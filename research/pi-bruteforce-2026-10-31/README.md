# π 有理逼近的可运行爆破解

日期：2026-10-31。对应 lain 的要求：先做实际搜索，保存能复查的结果。

本目录提供一个仅依赖 Python 标准库的程序。它逐个检查指定范围内的所有正整数分母，记录绝对误差和分母平方归一化误差的新纪录；也提供真正逐对枚举的矩形穷举模式。程序不使用连分数、素数筛选或浮点 π 来决定胜负。

## 直接运行

在本目录运行：

```bash
python3 search.py --max-q 10000000 --output results_10000000.json
```

指定分子、分母区间，逐对穷举：

```bash
python3 search.py --min-p 150 --max-p 380 --min-q 50 --max-q 120 --exhaustive --output rectangle.json
```

同一个矩形，保留每个分母下的最优分子，得到完全相同的每层纪录：

```bash
python3 search.py --min-p 150 --max-p 380 --min-q 50 --max-q 120 --output rectangle_fast.json
```

从更后的分母继续扫描一段：

```bash
python3 search.py --min-q 10000001 --max-q 20000000 --output next_segment.json
```

这一命令返回新分段内的纪录，不会自动加载或合并前一段的纪录。不同分段可以独立运行；比较各段最终最小值即可合并有限区间的最优解。

结果写入 JSON，进度和最终摘要写入标准错误；不指定 `--output` 时，JSON 写入标准输出。`--progress-every 0` 关闭中途进度。默认额外认证 64 位 π 原生单位数位并计算两个获胜分数处的迁移区间；`--native-digits 0` 可关闭此项。

## 搜索的对象

记分子为 p，分母为 q，两个指标是

\[
E(p,q)=\left|\pi-\frac pq\right|,
\qquad K(p,q)=q^2E(p,q)=q|q\pi-p|.
\]

固定 q 时，两者都在最接近 qπ 的整数处最小：

\[
p(q)=\left\lfloor q\pi+\frac12\right\rfloor.
\]

若分子限制在整数区间 `[min-p,max-p]`，再把这个整数截到该区间内即可。这来自绝对值在目标左右的单调性。因此扫描 `q=1,...,N`，每个 q 只检查这个 p，不会漏掉这两种目标的最优分数。它不是枚举所有有理数表示，而是利用目标函数省去同一行中不可能获胜的表示。

普通模式每次成功完整扫描有 O(N) 次整数算术操作；有 n 个分子、m 个分母的逐对模式是 O(nm)。这些是算术操作数，不是把大整数算术当作免费的位复杂度结论。精度不足时程序提高精度并重扫，重试次数另行记录。当前实现保存全部新纪录，空间为 O(R) 个纪录，其中 R 是实际纪录数，而非 O(1)。

`K` 使用输入的原始 q。输出同时给出约分后的分子分母，但不会悄悄改用它们评分。例如只允许 `710/226` 的矩形中，原始 K 是 `355/113` 的四倍。对于默认 `1<=q<=N`、不限制分子的搜索，约分表示也在范围内，所以此区别不会漏掉真正最优的约分分数。

## 如何认证，而非仅用小数猜测

程序使用恒等式

\[
\pi=16\arctan(1/5)-4\arctan(1/239)
\]

和反正切交错级数相邻部分和，得到有理外包区间，再向外舍入成

\[
L/2^B<\pi<U/2^B.
\]

默认 B=160。每个 q 的最近整数判定，都要求区间两端给出同一个候选；每次新纪录比较，都要求两个误差区间严格分离。区间重叠时，程序将 B 翻倍并从头重扫。相同有理数造成的绝对误差平局，通过整数交叉相乘直接识别。

给定 p,q，先包围带符号残差

\[
\frac{p2^B-qU}{2^B}<p-q\pi<\frac{p2^B-qL}{2^B},
\]

再取绝对值、除以 q 或乘以 q，分别得到 E、K 的严格可用区间。所有胜负判断使用整数运算。JSON 保存整数端点和分母；显示用的小数也向外舍入，不参与判断。

有限范围内增精度会终止：π 的无理性排除了最近整数半点平局，也排除了两个不同有理数对 π 的绝对误差相等；两个不同的正整数对也不能具有相等的 K，否则相等式会推出 π 有理。重复表示的 E 平局单独处理。

## 本次实跑结果：一千万个分母

完整文件：[results_10000000.json](results_10000000.json)。

- 范围：`1 <= q <= 10,000,000`，正整数分子不设上界。
- 实际检查：10,000,000 个每层最优候选，覆盖该范围内两种目标的全局最小值。
- 精度：160 位；增精度重试：0 次。
- 本环境搜索耗时：约 14.49 秒，不含随后生成原生数位与迁移报告的时间；其他机器耗时会变化。
- 保存 169 次绝对误差新纪录、3 次 K 新纪录。

| 目标 | 范围内最优分数 | 指标近似值 |
|---|---|---|
| 绝对误差 E | 5419351/1725033 | 2.2144779300394 × 10⁻¹⁴ |
| 归一化误差 K | 355/113 | 0.0034063119301380705 |

K 的三次新纪录依次为：

| 分数 | K 的近似值 |
|---|---|
| 3/1 | 0.141592653589793 |
| 22/7 | 0.0619599741001313 |
| 355/113 | 0.00340631193013807 |

所以在这个有限分母范围内，绝对误差继续缩小，但 K 尚未超过 355/113 的表现。特别地，范围内没有满足 `|π-p/q| < 1/(300q²)` 的正整数对；这不排除更大的分母。

这些是本次有限扫描的认证结果，不声称产生新的 π 逼近纪录，也不证明或证伪 P2848。

## 与进制迁移的连接

固定 π 的单位数位 `d_j`，定义

\[
F(t)=\sum_{j\ge1}d_jt^{-j},\qquad F(\pi)=1.
\]

程序在两个获胜分数 t=p/q 处另行计算 `F(t)-1`。数位由 π 区间直接认证，不输入 π 的十进制数字串。M 位截断的尾界为

\[
0\le F(t)-\sum_{j=1}^M d_jt^{-j}
\le\frac{3t^{-M}}{t-1},\qquad t>1.
\]

本次结果：

| 有理底数 t | F(t)-1 的近似值 |
|---|---|
| 355/113 | −9.41457569585097 × 10⁻⁸ |
| 5419351/1725033 | −7.81528145266271 × 10⁻¹⁵ |

这些迁移值是对已找到候选的额外观察，没有用于未经证明的剪枝。若指定矩形中的获胜分数不大于 1，则程序明确跳过该迁移级数。
