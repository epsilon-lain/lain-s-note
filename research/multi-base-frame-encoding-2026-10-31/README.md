# 多原生底数区间的并行观测帧：单时钟笛卡尔编码

日期：2026-10-31

## 1. 模型解释

用户确认的结构是：

- 每个长度为 1 的实数区间对应一个不同的原生底数（或一个原生底数附近的迁移窗口）；
- 每个区间划分为 n 个观测帧；
- 同一轮全局观测在每个区间各选一个帧；
- m 个区间的帧选择组合成一个状态，总状态数为 n^m；
- 希望用单一时钟 T 遍历全部组合，并把组合读成有理数。

需要区分三类对象：
1. 区间标签/原生底数 β_j；
2. 局部观测帧编号 k_j；
3. 由全部帧编号组成的有理数读出。

## 2. 区间与帧

取 m 个互不混淆的长度为 1 的参数区间
\[
I_j=[\beta_j,\beta_j+1],\qquad j=1,\ldots,m,
\]
其中 β_j 是第 j 个原生底数标签。若迁移只在 t>β_j 有定义，则应将区间平移为 [β_j+ε_j,β_j+1+ε_j]，或只取其定义域内的子区间；这里先把长度为 1 的窗口视为已选定。

将每个区间等分为 n 个帧。使用帧中心避免边界双重归属：
\[
t_{j,k}=\beta_j+\frac{k+1/2}{n},
\qquad k=0,\ldots,n-1.
\]
第 j 个区间的一帧选择 k_j 对应一个观测位置 t_{j,k_j}。

若第 j 个原生底数 β_j 产生固定数位对象 d^{(j)}=(d^{(j)}_\ell)，其迁移函数为
\[
F_j(t)=\sum_{\ell\ge1}d^{(j)}_\ell t^{-\ell},
\]
则该帧读取
\[
y_j=F_j(t_{j,k_j}).
\]
一次联合观测是向量 (y_1,\ldots,y_m)，不是自动等于某个单一有理数。

## 3. 单时钟遍历 n^m 个组合

令 T=0,1,\ldots,n^m-1。把 T 唯一写成 m 位 n 进制：
\[
T=k_1n^{m-1}+k_2n^{m-2}+\cdots+k_m,
\qquad 0\le k_j<n.
\]
于是 T 唯一决定所有区间的帧编号。每个 T 对应一个联合观测状态；不同 T 对应不同帧组合。全部 n^m 种组合恰好遍历一次。

这一设计中，用户只输入/推进一个全局时钟 T。k_1,...,k_m 是内部解码状态，并非额外自由输入。

## 4. 有理数读出

把帧编号作为 n 进制数字，定义
\[
\boxed{X(T)=\sum_{j=1}^m\frac{k_j}{n^j}=\frac{T}{n^m}.}
\]
因此 X(T) 是 [0,1) 中的有理数，且
\[
\{X(T):0\le T<n^m\}
=\left\{0,\frac1{n^m},\ldots,\frac{n^m-1}{n^m}\right\}.
\]
这是 n^m 个不同的有理数，且一一对应全部帧组合。

若要扫描 [0,L) 的有理网格，可定义 X_L(T)=L T/n^m（L 为正整数或有理数）。若要扫描任意有限区间 [A,B)，定义
\[
X_{A,B}(T)=A+(B-A)\frac{T}{n^m}.
\]
当 A,B 为有理数时，全部读出仍为有理数。

重要：X(T) 是帧组合的编码读出；它不等于观测向量 (y_1,...,y_m)，也不自动等于任何一个 F_j(t_{j,k_j})。若希望“迁移函数的观测值本身”决定有理数，必须另给一个读出函数 Ψ(y_1,...,y_m)，并证明其有理性、单射性及尺度性质。

## 5. 观测时间与速度

若 T 每单位物理时间推进 ν 次，则全局组合扫描速度为 ν 个状态/时间。局部第 j 区间的帧编号由 T 的第 j 个 n 进制数字给出；当低位数字进位时，高位状态改变。因此局部状态不是同时匀速连续移动，而是数字轮转/进位过程。

对单个区间，帧中心间距为 1/n。若把离散帧编号连续插值成局部坐标
\[
u_j(\tau)=\beta_j+\frac{k_j(\tau)+1/2}{n},
\]
则在不发生进位/重置的局部时段，速度为
\[
\dot u_j=\frac{\dot k_j}{n}.
\]
全局编码读出满足 X(T+1)-X(T)=1/n^m。物理时间下的平均读出速度为 ν/n^m。

若需要每个区间都单调扫过 n 帧，而不是按 n 进制计数器轮转，则不能同时保证只用 n^m 个时钟状态覆盖全部笛卡尔组合且每个坐标单调；必须允许回绕，或增加扫描时间/采用 Gray code 等改变相邻状态差异的调度。

## 6. 能做什么，不能自动做什么

可直接保证：
- m 个不同原生底数窗口，每个 n 帧；
- 恰有 n^m 个联合观测组合；
- 一个整数 T 一一遍历所有组合；
- 一个有理读出 X(T) 一一编码全部组合；
- 任意有限有理区间可通过仿射变换得到有理网格。

不能仅由组合计数推出：
- 每个观测向量都含有独立的数学信息；
- 不同组合下的函数值一定不同；
- 观测值本身是有理数；
- n^m 个组合就等于 n^m 个有理逼近质量不同的分数；
- 采样扫描自动找到 π 的异常好逼近。

这些需要针对 F_j 的单射性、数值分离、噪声容限、读出映射和逼近归一化尺度逐一证明。

## 7. 与 π 逼近的接点

若某个区间专门对应 π 原生迁移函数 F_π，帧中心为
\[
t_k=\pi+\frac{k+1/2}{n}
\]
（或选在 π 右侧的长度 1 窗口），则观测偏差
\[
|F_\pi(t_k)-1|
\]
由正割线因子与 |t_k-π| 双向比较。若希望扫描 π 两侧，应采用包含 π 的窗口，并分别处理两侧；不能把帧中心恰好取 π 的情况当作有理底数，因为 π 本身无理。

更一般地，多个原生底数 β_j 的区间可以同时采样，构成联合特征向量；之后可研究哪些组合在不同原生底数之间有相同/近似的迁移响应。

若目标是枚举所有有理数 p/q，而不是某个固定有理网格，则应让 n、m 或区间数量随扫描层级变化，或另加可逆有理解码。固定 n,m 只能给出有限网格，不可能覆盖所有有理数。

## 8. 关键概念边界

- “每个区间对应一个原生底数”是不同函数/不同数位对象的标签。
- “区间长度 1”是该原生底数的迁移参数窗口。
- “n 个观测帧”是每个窗口内的离散采样分辨率。
- “n^m 种组合”是笛卡尔积状态数。
- “一个时钟 T”是组合状态的单参数枚举。
- “有理数读出”是对帧编号的编码，不应与迁移函数的实数/复数观测值混为一谈。

本模型先固定这些定义。后续最重要的设计问题是：是否存在一个由联合观测向量自然诱导、同时保持有理性和逼近尺度的读出 Ψ，而不是人为再指定一个编码。
