# 整群有理根、正弦归一化与批量分母认证
2026-11-02

结论与范围

本轮实际完成：
1. 对用户提出的整群有理根给出精确 Gamma／正弦表达。
2. 证明原始乘积除以 q! 的指数小值本身不保证特别好的单根逼近；给出严格二次无理数对照。
3. 对全部实际既约分母 1<=q<=10^100 完成有限质量认证：q^2|pi-p/q| 的唯一最小者仍为355/113。
4. 以逐分母整数扫描到10^6、独立连分数证书交叉复核。
5. 另实现直接作用于根族的有理条带 floor_sum 区块搜索，见对应脚本和JSON。

没有新的 pi 逼近纪录，没有证明质量趋零的无限子序列，也没有决定 pi 的坏逼近性。
本轮计算只认证有限范围，搜索输入包含由经典恒等式认证的 pi 有理区间。
已知结式、Gamma、Beta、连分数及欧几里得取整求和工具不作为首创。

一、对象及真实分母

q 为正整数。定义
  F_q(x) = product_{k=0}^q (q*x-3*q-k).
其根恰为 (3q+k)/q，k=0,...,q，全部位于[3,4]。
令
  D(q) = min_{k=0,...,q} |pi-(3q+k)/q|.
由于3<pi<4，最近整数一定落在[3q,4q]，所以
  D(q)=||q*pi||/q,
  q^2 D(q)=q ||q*pi||.
||t|| 表示 t 到最近整数的距离。

此处q是生成分母。对输出p/q，设g=gcd(p,q)，实际分母为q/g，质量是
  (q/g)^2 |pi-p/q| = q|q*pi-p|/g^2.
若q^2D(q)沿子序列趋零，约分后的质量也趋零。实际分母必趋于无穷：否则[3,4]内只有有限个可能的既约输出，与pi的正距离无法趋零。
反过来，任意实际分母趋于无穷的质量趋零序列，都被本根族覆盖，并有q^2D(q)<=q^2|pi-p/q|。
所以此根族没有遗漏目标；这不等于已经证明目标会发生。

二、整群根在pi处的精确式

令alpha=pi-3，t=q*alpha。Gamma递推给出
  F_q(pi)=Gamma(t+1)/Gamma(t-q).
再用反射公式 Gamma(z)Gamma(1-z)=pi/sin(pi*z)，得到
  F_q(pi)=(-1)^q Gamma(t+1)Gamma(q+1-t) sin(pi*t)/pi.

因此正的非振荡尺度因子为
  Gamma(t+1)Gamma(q+1-t)/pi，
去掉它以后，算术小值信号恰为 sin(pi*q*(pi-3))。
因3q为整数，绝对值还满足
  |sin(pi*q*(pi-3))| = |sin(pi^2*q)|.

对任意实t，2||t||<=|sin(pi*t)|<=pi||t||。证明：只需在d=||t||属于[0,1/2]上用正弦的凹性下界sin(pi*d)>=2d，以及sin u<=u。
故
  q|sin(pi^2*q)|/pi <= q^2D(q) <= q|sin(pi^2*q)|/2.
爆破目标等价于：q|sin(pi^2*q)|沿某个整数子序列趋零。
这是目标的精确波形表示；没有独立证明所需的整数采样小值。

三、乘积的普遍指数包络不能冒充爆破

更一般固定x属于(3,4)，令a=x-3，rho=a^a*(1-a)^(1-a)，则0<rho<1。
Beta积分给出
  Gamma(qa+1)Gamma(q(1-a)+1)/q!
    =(q+1)*integral_0^1 [u^a(1-u)^(1-a)]^q du
    <=(q+1)*rho^q.
最后一步因为括号内函数在u=a取得最大值rho。
于是
  |F_q(x)|/q! <= (q+1)*rho^q/pi ->0.
该式对任意固定内部目标x都成立。

严格对照：取x*=2+sqrt(2)。任意本族根r=p/q属于[3,4]都有
  q^2|x*-r|
    = |(p-2q)^2-2q^2|/(r-2+sqrt(2))
    >=1/(2+sqrt(2)).
分子是非零整数；分母为正且不超过2+sqrt(2)。这个目标有统一正质量下界，但归一化根乘积同样指数趋零。
因此要分析单根逼近，必须保留根标签及适当尺度，不能只看总乘积的小值。

四、两个可直接使用的精确根族接口

在根r=3+k/q处，只有第k个因子的导数项非零：
  F'_q(r)=q*(-1)^(q-k)*k!*(q-k)!.
这给每个根一个明确的局部尺度。

分母放大m倍（m为正整数）时：
  F_{mq}(x)=m^(q+1)F_q(x)
             *product_{0<=k<=mq, m does not divide k}(mq(x-3)-k).
旧根完全保留，约分后也完全相同。新增分母层的改进只能来自新增的根。

五、有限范围的全部有理数认证

用Machin恒等式
  pi=16atan(1/5)-4atan(1/239)
及交错级数给出纯有理上下界。主验证用220项与75项，区间宽度约2.061e-310；独立程序用200项与70项。

Machin恒等式也可直接验算：tan(4atan(1/5))=120/119，再减去atan(1/239)后正切恰为1；该角位于(0,pi/2)，故等于pi/4。

对区间两端同步取整数部分和倒数，得到确定属于pi的共同连分数前缀。主程序得到305个共同系数，本次仅使用截止首个越界分母所需的195个。
全部q<=10^100的收敛分数共194个，各项均保留精确质量区间，整数gcd为1。
第一项越界分母为
  11861370656940517106115970314230542917832783292279765360251185207749769595904108589726721941267812387.

记录改善只有
  3/1       质量约0.14159265358979323846
  22/7      质量约0.06195997410013131533
  355/113   质量约0.00340631193013807050663890402767168634.

完整覆盖所用的经典输入是Legendre判据：既约p/q若|pi-p/q|<1/(2q^2)，必为连分数收敛分数。
任何可能击败355/113的分数都满足该判据；194个候选中，所有其它项的质量下界都严格大于355/113的质量上界。因此覆盖的是全部实际分母，不只采样收敛分数。

主程序还不使用连分数，逐个扫描q<=10^6：用向外取整的90位十进制有理pi区间，精确认证每个q的最近分子，保留607981个互素候选。记录序列相同。
这项交叉检查没有把百万分母测试误报为10^100范围的穷举；大范围覆盖分别由经典判据和独立区块算法支撑。

六、直接批量处理根的区块算法

设L<=pi<=U均为有理数，质量阈值tau>0。对一段分母A<=q<=B，如果
  q^2|pi-p/q|<tau，
则必有
  qL-tau/A < p < qU+tau/A.

因此该加宽条带中的整数对数量恰为
  C(A,B)=sum_{q=A}^B [ceil(qU+tau/A)-floor(qL-tau/A)-1].
两个有理仿射函数的取整和可由欧几里得floor_sum精确计算，避免逐个q或逐个p枚举。
若C=0，整段无需再查。若C>0，二分区块直到单个q，再直接认证真正质量。
初始用[A,2A-1]的倍增区块，直到指定有限上界。此法不展开根多项式，也不调用连分数作为搜索输入。

本轮阈值tau=1/250，分母上界10^100。实际覆盖333个初始倍增区块，共345个节点：338个零计数排除块、6个二分块、1个评分叶子。总计690次floor_sum调用、64294次欧几里得循环。唯一叶子为q=113、p=355；0未决。完整节点证书见independent/batch_floor_search_1e100.json。
因此区块证书本身就足以完成有限范围内的唯一最优证明：355/113的质量小于1/250，而阈值以下只存在它。连分数在这条算法中只作事后独立复核，没有作为搜索输入。
主程序另用220/75项得到的不同pi有理区间重跑，全部区块的边界、计数和状态与原200/70项结果完全一致，见batch_verification.json。这次重跑共享floor_sum实现，不冒称另一份独立floor_sum算法。

floor_sum的基础递推也可直接检查。记S(n,m,a,b)=sum_{i=0}^{n-1}floor((ai+b)/m)。先把a、b分别作带余除法，整商部分贡献(a//m)*n(n-1)/2+(b//m)*n。余下0<=a,b<m时，若an+b<m，和为0；否则置n'=(an+b)//m、b'=(an+b)%m，格点转置给出S(n,m,a,b)=S(n',a,m,b')。反复整数化和交换即为代码的欧几里得循环。这里使用Python任意精度整数，没有固定字长溢出。
零计数节点的排除是严格的，因为使用的是必要条件；正计数节点仅表示仍需检查。
所有判断使用整数或Fraction；浮点显示值不参与判定。
本轮的有限运行效率不构成该算法在任意目标/精度下的统一复杂度定理。
