# 整群有理根、角度构造、预设约分与 π 纪录核验

2026-11-02。本目录整理本轮完整讨论中可复用的数学结果、算法、失败实例、猜想与证据，不只收录末尾的纪录讨论。接续仓库 `f858424fbf451673adb44abe38c23268b4447c6e`，不替换既有构造主线。

对互素整数 $p,q$，其中 $q>0$，统一使用实际既约分母的质量

$$\mathcal Q(p/q)=q^2|\pi-p/q|.$$

本项目所说的“爆破解”是普通有限整数分数组成的无限子序列，使该质量趋零。每个分母有限，但整列可以无界。本轮**尚未构造成功这样的子序列，也未决定 π 的坏逼近性**。

## 最重要的公式

设 $D(q)=\min_{0\le k\le q}|\pi-(3q+k)/q|$，$\|t\|$ 表示到最近整数的距离，则

$$D(q)=\frac{\|q\pi\|}{q},\qquad
\frac{q|\sin(\pi^2q)|}{\pi}\le q^2D(q)\le\frac{q|\sin(\pi^2q)|}{2}.$$

这使整群根的目标变成整数采样的波形小值问题；并未独立证明无限小值发生。对 $2+\sqrt2$ 的严格对照表明，根乘积的普遍指数小包络不能充当单根逼近的证据。

旋转链若满足 $pd-qc=1$，$p/q>\pi>c/d$，定义 $e=p-\pi q$、$z=(\pi d-c)/e$、$\gamma=qe$、$\eta=k-z$，则

$$\mathcal Q\!\left(\frac{pk+c}{qk+d}\right)=|\eta|(1+\gamma\eta).$$

该精确关系说明：预设约分已经实现，但后续新读数 $z$ 需要再次靠近整数。当前规则没有保证这件事反复发生。

## 复现

要求 Python 3.9 或以上；核心只用标准库。`mpmath` 若已安装，仅用于根族的辅助数值交叉检查。

```sh
python3 research/root-angle-record-2026-11-02/run_all.py
```

该入口在本目录依次重新生成根族完整证书、区块树、两轮旋转、208 项核对照和首次纪录改进证书，随后独立回放。较大的逐项 JSON 由脚本本地重建，不把重复的大整数区间全部存入 Git。`PRIOR_VERIFICATION.json` 留存整理前的紧凑核验记录；`VERIFICATION.json` 保存本次整理版本的实际执行记录。

最新约 6535.2 亿项的作者计算**不在该复现范围内**；没有把小型公式测试或日志一致性检查冒充整次计算的验证。没有 Lean 形式化证明。既有经典公式与已知分数均按工具和基准记载，不作首创声明。
