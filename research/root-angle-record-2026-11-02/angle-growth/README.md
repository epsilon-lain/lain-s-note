# 有限整数分母下的成长函数、角度选择与预设约分
2026-11-02

本轮目标

接续用户的原成长函数族，尝试在某个方向通过相消与约分制造异常好的pi有理逼近。
每个候选分母都是普通、有限、完全约分后的正整数。允许一列这样的整数无统一上界；没有把无穷大、pi或非整数方向参数当成整数分母。

完成了两条可复查构造，尚未构造出质量趋零的无限子序列。
角度构造恢复355/113为已知基准，不作为新纪录；第二轮普通误差下降、实际质量恶化。
另外构造了同一采样分母预算中的六阶角核，普通误差相消严格成立，有限真实质量仍不好。

一、原成长族的直接角向接入

设G_1={f:R->R : f(n)=n 对所有整数n}。原族只规定格点读数。
对实数t，令u={t}为小数部分，定义
  H(t)=16u^2(1-u)^2.
H是1周期C^1函数，整数点为0、半整数点为1，且0<=H<=1。
对有限非零整数b，取复值调制器
  g_b(t)=1-i H(t)/b.
其相位随t变化，整数点精确为1；它是原共享调制器的两个实坐标扩展，并非偷偷把实值函数当成复值函数。

给定普通整数方向z=q+ip，把实数t作为共同观测时钟，定义
  V_b(t)=t(q+ip)g_b(t).
因此V_b(n)=n(q+ip)，两坐标在整数钟上仍读出qn、pn。
在半整数钟上，读取斜率Im V/Re V，公共实尺度t消掉，得到
  (bp-q)/(bq+p).
清除b并完全约分以后，输出仍为普通整数比。

这里新增的是中间时刻的方向读数。g_b每周期的净相位变化仍为0，所以没有声称整数骨架或总周期已经改变。若只在原来的整数点读数，相位自由度本来就不改变输出；此构造明确采用半整数读出并对清分母收费。

二、先规定共同因子，再选角度

一般旋转正切a/b（a,b互素，b>0）后，原始整数方向为
  P0=bp+aq，Q0=bq-ap.
若p,q也互素，G=gcd(P0,Q0)一定整除
  gcd(p^2+q^2,a^2+b^2).
这由两次高斯整数共轭相乘及互素性直接证明。

本轮固定a=-1，记N=p^2+q^2。由于gcd(q,N)=1，可在生成前规定
  b == -p*q^{-1} mod N.
这样N同时整除P0、Q0；一般整除界又给G|N，因此G恰为N。
并非人为把原始系数乘同一个N。

具体地，对q>1计算0<d<q的模逆d=p^{-1} mod q，并令c=(pd-1)/q。
于是pd-qc=1。置b0=(Nd-p)/q，取b=b0+Nk，k为非负整数，则完全约分后的候选恰为
  P_k=pk+c，Q_k=qk+d.
所有候选互素，因为p Q_k-q P_k=1。每一项Q_k都是有限整数。

该角链是经典幺模整数方向链，和Farey/连分数结构相连，角度重述本身不作为新增算术定理或新纪录。

三、两轮实际验证和整个一参数链的最优性

输入p/q>pi，且canonical mate c/d<pi。定义
  e=p-pi*q>0，h=c-pi*d<0，z=-h/e。
真实质量为
  gamma(k)=(qk+d)|ek+h|。
根左侧为凹二次函数，根右侧严格递增。因此整个无限k>=0链的最优整数只需比较
  0、floor z、ceil z。
本轮用Machin有理积分余项界自适应认证floor z与三项质量排序，不输入已知目标分数、不输入pi小数，也不调用连分数搜索。
它确实使用了pi恒等式提供的有限信息，不称完全盲发现。

首轮：输入22/7，mate3/1。
  N=533，b0=73，自动选择k=16，b=8601。
  原始方向189215/60229，gcd恰533，输出355/113。
  质量从约0.0619599741下降至0.00340631193，改善超过18倍。
  参数选择只需atan(1/5)4项与atan(1/239)2项的有理积分界。

第二轮：原样输入355/113，mate333/106。
  N=138794，b0=130193，自动选择k=293，b=40796835。
  原始方向14482876312/4610042710，gcd恰138794。
  输出104348/33215，质量约0.3658638091，为输入的107.4076倍。
  参数选择需要7项与3项。

这轮失败不归因于扫描上界：比较的三个整数已经覆盖此一参数角链的全局最优。
更精确地，令gamma=q(p-pi*q)，eta=k-z，则
  gamma_new=|eta|(1+gamma*eta).
该式由e(d+qz)=1直接得到，没有小角近似。要接续质量改善，需要新角读数z再次异常接近整数；当前规则没有保证这一点。

四、相对方向相消，保留共同采样分母

还尝试了角积分族。令u属于[0,1]，B=u(1-u)，对s>-1定义
  P_s=(1-u)^2+sB，Q_s=u^2+sB。
复向量P_s+iQ_s不为零，连续角从0到pi/2；角核
  K_s=2(P_s Q_s'-Q_s P_s')/(P_s^2+Q_s^2)
精确积分为pi。

取s±=(1±sqrt(5))/2的两个共轭方向，令K0=(K_s+ +K_s-)/2。
定义整系数多项式
  P=(1-2u)(1-B)，Q=B(1-2B)，D=P^2+Q^2。
则
  K0=(1-6B+12B^2-4B^3)/D，积分pi。
两个方向的差给出纯有理零积分方向
  J=(5-30B+40B^2-20B^3)/D，积分0。

选择由端点导数条件决定的权重3/5，得到
  K*=K0+(3/5)J=4P^2/(P^2+Q^2)，积分仍为pi。
sqrt(5)与权重分母5均在代数化简后消失，最终核为整系数多项式的比。
因此没有把代数数放进整数分母，也无需用Fibonacci有理数逼近sqrt(5)。

K*的一阶、三阶端点导数差精确为0，五阶、七阶差分别为5760、645120。
N段复合梯形读数T_N满足
  T_N(K*)-pi=4/(21N^6)-8/(15N^8)+O(N^-10)。
未加权K0的首误差为1/(5N^4)。这些是普通积分误差的结论。
K*和K0在相同有理节点可使用同一个未约分公分母；这不意味着实际既约分母总不增加。

有限208项候选中，K*梯形在34个节点规模中的32个优于K0梯形；N=21、26时实际分母分别增加7倍、13/2倍，质量反而更差。
K*组绝对最优只有4/1，质量约0.8584；全部对照最佳是3/1，没有pi新纪录。
这说明角相消与共享原始分母已经一起实现，但实际gcd及其规模增长仍未闭合。

五、一个对每个有限N都有效的纯有理余项界

为避免只给渐近符号，主验证另给出严格全指标上界。
记v=(u-1/2)^2>=0，有精确平方和展开
  D=1/64+(9/4)v+(11/2)v^2+4v^3+4v^4 >=1/64。
因此全区间没有极点。

设A0=4P^2，递推
  A_{j+1}=D A_j'-(j+1)D' A_j，
就有K*^(j)=A_j/D^(j+1)。六阶分子系数绝对值总和恰为
  ||A6||_1=3762014500993449600。
故sup|K*^(6)| <=64^7 ||A6||_1。

Euler-Maclaurin的m=3积分余项中，前两项端点差已经为0。
B6(x)=x^6-3x^5+(5/2)x^4-(1/2)x^2+1/42，
B6'(x)=x(x-1)(2x-1)(3x^2-3x-1)。
在[0,1]，B6范围为[-31/1344,1/42]，所以|B6-B6({Nu})|<=3/64。
直接得到对全部普通正整数N成立的保守界
  |T_N(K*)-pi| <= C6/N^6，
  C6=1077181949922975036148285440。
这个常数很松，但完全有理、有限、可复算，不需要pi小数。
若T_N约分后分母为q_N，联合质量上界只能写成q_N^2*C6/N^6；没有将普通N^-6收敛冒充丢番图质量趋零。
