# 有限整数、复值成长方向与预设范数约分
2026-11-02

范围：本笔记给出一条实际可执行的角度构造、两轮精确输出，以及整个一参数链的全局最优证书。没有新pi逼近纪录，没有证明无限质量改善。

1. 原成长族中的角方向接口

令H是1周期的实函数，在[0,1]上取
  H(t)=16 t^2(1-t)^2.
它的周期延拓为C^1，H(n)=0，H(n+1/2)=1，且0<=H<=1。
对有理s，取复值乘子
  g_s(t)=1+i s H(t).
这时g_s(n)=1，实部恒为1，所以从不经过0，有连续相位，且每个单位区间的净相位变化为0。
由F_{T,s}(x)=x g_s(Tx)，当Tq为整数时仍有F_{T,s}(nq)=nq；这是原共享成长族的复值扩展。实标量乘子只缩放而不改变方向，这里明确加入第二分量。
对一个非零整数方向z=q+ip，在中点读出z*g_s(1/2)。若s=a/b，则它的方向由
  Q0=bq-ap,
  P0=bp+aq
确定。b是有限正整数，a是有限整数。归一化为单位向量所需的平方根无须进入分数P0/Q0；允许保留正的径向缩放。
这只改变内部读出方向。g的零端点性质保证总相位变化仍为0，不能把它误报为新的端点周期常数。

2. 有理旋转的精确分母费用

若gcd(p,q)=gcd(a,b)=1，令G=gcd(P0,Q0)，则
  G divides gcd(p^2+q^2,a^2+b^2).
证明：将Gaussian乘积(q+ip)(b+ia)=Q0+iP0分别乘以两个共轭，可知G整除(p^2+q^2)a与(p^2+q^2)b，以及(a^2+b^2)p与(a^2+b^2)q。两组互素性分别给出结论。
实际输出为P=P0/G，Q=Q0/G。这个G要实际核查，不得把有理旋转参数当成免费。

以下固定a=-1，处理输入p/q>pi。
置N=p^2+q^2。因为gcd(q,N)=1，预先规定
  b == -p*q^{-1} (mod N)
就保证N同时整除bp-q与bq+p。
前述一般整除又给G divides N，所以此处G恰等于N。

3. 预设完整约分后得到的整数方向链

用p,q自身算出canonical Bezout mate：
  d = p^{-1} mod q, 0<d<q,
  c = (pd-1)/q.
于是pd-qc=1。令
  b0=(Nd-p)/q,
  b=b0+Nk, k>=0.
直接代入可得旋转并完全约分后的整数方向
  P_k=pk+c,
  Q_k=qk+d.
对所有k，pQ_k-qP_k=1，因此gcd(P_k,Q_k)=1。
这是一条真正的幺模分数链，完整约分因子是生成前保证的N，不是把所有系数共同乘N。
恒有
  P_k/Q_k=p/q-1/(q Q_k).

4. 角误差、理想方向与完整链质量

记alpha=pi，e=p-alpha q>0，h=c-alpha d。这里两轮都严格认证h<0。
目标方向与输入的夹角为
  Delta=atan(p/q)-atan(alpha)=integral_alpha^{p/q}du/(1+u^2).
其正切为e/(q+alpha p)。旋转tan(phi)=-1/b后，零误差理想参数为
  b*=(q+alpha p)/e.
定义z=-h/e，有
  e(d+qz)=pd-qc=1,
  b*=b0+Nz.
故选择整数k就是用整数格近似理想角读数z，所有候选仍有普通有限整数分子分母。

实际约分后的质量为
  gamma(k)=Q_k^2|alpha-P_k/Q_k|
          =(qk+d)|ek+h|.
在0<=k<=z，gamma(k)是二次项系数为-qe<0的凹二次式，所以该整数区间的最小值在k=0或floor z。
在k>=z，导数为2qek+de+qh；于k=z时为de-qh>0，且之后递增，所以这一段的最小整数点是ceil z。
因此整个无限k>=0链的全局最小值，只需比较
  k=0, floor z, ceil z.
这不需要任意指定扫描上界。

5. 用有理积分界生成选择，不灌入已知输出

初始输入只有22/7。
pi的有理上下界来自Machin恒等式以及atan(1/b)=integral_0^{1/b}dt/(1+t^2)的有限几何级数与交错余项界。脚本从少量项开始自适应加精度，直到z的floor及三个候选的质量区间严格分离。
整个选择过程不使用pi小数、已知355/113或104348/33215，不调用连分数程序。
若L<pi<U且p/q>U，夹角也有直接的有理积分界
  ((p/q)-U)/(1+(p/q)^2) <= Delta
       <=((p/q)-L)/(1+L^2).
脚本同时保存了更精确的正切角误差区间。

首轮：
  输入22/7，mate=3/1，N=533，b0=73。
  用atan(1/5)的4项与atan(1/239)的2项选出k=16。
  b=8601，raw=(189215,60229)，gcd=533。
  输出355/113，实际质量约0.00340631193013807050664。
  与输入的质量比约0.05497600635909322，即严格改善超过18倍。

第二轮：
  把首轮输出原样作为输入355/113，mate=333/106。
  N=138794，b0=130193。
  相同规则用atan(1/5)的7项与atan(1/239)的3项选出k=293。
  b=40796835，完整gcd=138794。
  输出104348/33215，实际质量约0.36586380906794851031。
  与输入的质量比约107.40760581287，质量恶化。

这两项都是经典已知分数；本笔记提供角方向、先验公因子、有限参数选择与第二轮完整费用的具体接口，不作新纪录或基础理论首创声明。
该方向链由SL_2(Z)整数矩阵给出，临界z也是目标alpha的Mobius变换。其整数取整选择与经典Farey/连分数结构相连，换成角语言不会额外保证新算术收益。

6. 接续缺口的精确标量式

令输入质量gamma=q e，eta=k-z。由e(d+qz)=1，得到
  gamma_new=|eta|(1+gamma eta).
括号为Q_k e>0。这是精确式，不是小角近似。
若f=z-floor z，则两侧临界点质量分别为
  floor侧：f(1-gamma f)，
  ceil侧：(1-f)(1+gamma(1-f))。
当输入gamma很小时，下轮质量主要由新读数z到整数的距离决定，输入的好质量没有自动保持。
首轮z异常靠近整数16，第二轮z位于292与293之间、离最近整数约0.3654；这精确说明了为什么同规则不能从355/113继续获得质量下降。
要得到无限质量改善，需要新增机制保证这些倒数角读数反复更靠近整数，或者改变可用整数方向并同时保留约分结构。现有一参数链自身没有给出该机制。
