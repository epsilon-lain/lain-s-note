# 单环正边证书：不可删判据与接近二倍的删除结果

本目录整理 Yohaku 原生研究阶段的一项一般证明及有限计算。核心结论是：在下面的固定图模型中，**不可删证书可以接近最优成本的二倍**；从完整目标图逐条删除冗余边，存在产生这种结果的删除次序。

模型只观察真边：候选图是 $2m$ 个固定标号顶点上的简单二正则图，围长至少 $m$，其中 $m\ge3$。目标是确认图的同构类型为一个 $2m$-环。每条观测边成本为1。“不可删”表示删除任一已观测边都会失去证书资格，不等于成本最小。

- [完整中文定义与证明](THEORY.md)：不可删区间充要判据、显式无限族、删除成本比上确界2。
- [AC 资源与宏附录](AC_APPENDIX.md)：已知8步距离上的新资源精化，以及严格限定语言中的批量表示成本64→55。
- [研究正文摘录](source/README.md)：保留原数学条目的英文正文或原样数学段落。
- [来源与哈希](PROVENANCE.json)：数学条目编号、原始源文件及产物的 SHA256；不包含聊天记录和私有运行标识。

完成判据与最优成本 $m$ 来自此前外部种子；本轮推导的是不可删区间判据及接近二倍的无限族。本目录不宣称文献首创。有限谱来自原生计算：例如 $m=6$ 的成本谱为 $\{6,8\}$，$m=12$ 为 $\{12,17,18\}$。一般定理由证明成立，不能靠有限表外推。

## 独立复核

只需要 Python 3 标准库，在本目录执行：

```bash
python3 verify_native_results.py
```

默认检查：$m=3\ldots12$ 全部分拆的逐切分判据；$m\le20$ 已存储的349个不可删模式；90个无限族有限实例；完整 AC 两个半径4球、全部8条最短路径、资源签名及单平坦宏优化。默认不重新枚举 $m=13\ldots20$ 的所有分拆；因此对这一段只独立检查所存模式的有效性。可以用 `--exhaustive-to 20` 显式扩展。

[external-verification.json](external-verification.json) 是**原生运行结束后新做的外部复核**，不能倒填为原生已有审阅或运行回执。程序不执行原研究代码，也不调用官方工具或上传平台。它验证冻结动作表中的数学结论；官方工具的另行验收应保留独立的来源与时间说明。

本轮原生应用结果没有缩短已有8/13步距离。新8步路径的 work 从旧见证49降为48；宏表示结果只适用于有限语料及明确计费语言，不代表原始步数减少或搜索加速。

本次另行完成的官方本地重放、CLI 回执与原生工作流证据，保存于 [Yohaku 原生研究审阅](https://github.com/epsilon-lain/yohaku/tree/codex/initial-release/research/native-theory-application-2026-11-16)。新路径通过固定官方版本的本地 CLI；没有平台上传。本目录的数学复核程序与该官方工具验收是两个独立步骤。

`source/` 还保留五份真正的原生研究算法与同伴核验源码，逐字提取、未在本次整理中执行；与后来另写的轻量复核程序分开。`data/native-results.json` 是为复核选取的公开原生数值数据，`data/ac-paths.json` 与 `data/ac-submission.txt` 则是原路径产物的逐字副本。
