# 相邻进制的面积峰值与尾项比较

2026-10-27。接续 DIGIT_RECTANGLE_INTEGRAL_2026-10-27.md，对用户提出的 1/q² 位置及 π 的尾项作区分。以下计算不声称文献首创，未进行 Lean 验证；不宣称证明 π 的逼近性质。

## 1. 所有大进制不可能一直低于固定的 1/q² 水平

固定 x∈(0,1)，p=q+1，E_{q+1} 是第 q+1 进制下波形与第一位数位横线之间的非负面积。记 B(q)=q²E_{q+1}，并记 ||y||=min_{a∈ℤ}|y−a|。

由于距最近网格点的误差至多是任取横线的误差、又至多是波面积，

    ||qx||/q ≤ E_{q+1}。

到整数集合的距离满足三角不等式，因此

    ||x|| ≤ ||(q+1)x||+||qx||
          ≤ (q+1)E_{q+2}+qE_{q+1}
          = B(q+1)/(q+1)+B(q)/q。                    (1)

因此，至少有一个相邻尺度具有

    max(B(q),B(q+1)) ≥ ||x|| q(q+1)/(2q+1)。        (2)

这里 ||x||=min(x,1−x)>0，与 q 无关，故 limsup_{q→∞}B(q)=∞。对于任何固定 C>0，E_{q+1}<C/q² 不可能对所有足够大的 q 成立。这个事实对任意非整数 x 都成立，不表明这些数是好逼近数或坏逼近数。

特别地，前文刘维尔数已经给出 liminf B=0；本节也说明其 limsup B=∞。相邻峰值一般事实更简单地解释了为什么不能把其好进制序列的结论扩展成所有大进制。

对 x=π−3，||x||=π−3。由 (1)：

    B(114) ≥ 114[(π−3)−B(113)/113]。

使用严格有理 π 上下界可证右侧大于 16.1275；数位有理区间检查给出 B(113)≈0.0138403963193、B(114)≈16.138126053。这里 B(113) 使用 114 进制，B(114) 使用 115 进制。数值只显示有限情况，(1) 是对所有 q 的证明。

## 2. 坏逼近数也可以无穷次落在 1/q² 下

以 sqrt(2) 为例。对任意整数 a 和正整数 q：若 a/q∈[1,2]，则

    |sqrt(2)−a/q|
      = |2q²−a²|/[q²(sqrt(2)+a/q)]
      > 1/(4q²)。

分子是非零整数，分母中的括号小于4。如果 a/q∉[1,2]，其距离大于1/4，也得到相同下界。因此 sqrt(2) 是坏逼近数。

从 (a,q)=(3,2) 开始，反复作 (a,q)↦(3a+4q,2a+3q)，满足 a²−2q²=1 且 q→∞，于是

    1/(4q²) < |sqrt(2)−a/q|
      = 1/[q²(sqrt(2)+a/q)] < 1/q²。

故小于某个固定倍数 1/q² 可以无限次出现，却不能单凭它断定好逼近。要达到 liminf q²|x−a/q|=0，必须沿无穷多个分母让系数也趋于0。对无理数 x，这个极限条件与不存在统一正的 C/q² 下界等价。

## 3. 位数尾项和实际分母

用户提及 π 在某个位置后的尾和小于1/N，尚未指定展开方式；必须根据具体展开核对。对于十进制数位的截断，定义

    T_N = π−floor(10^N π)/10^N。

则 0<T_N<10^(−N)<1/N，N≥1。截断分数的原始分母为10^N，约分后可能更小；其真实分母是约分后的 q_N，而不是数位位置 N。故 T_N<1/N 与 T_N<1/q_N² 是不同的比较。不能从前者推出后者，也不预设 π 的后者是否存在无穷多次。

同理，其他 π 级数（例如某个无穷级数截断）必须先写出具体公式、尾项和约分后的分母，再比较；不把位数、求和项数和分母混同。
