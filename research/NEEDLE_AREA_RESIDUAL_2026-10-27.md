# 将进制余波转成射线面积

研究记录，2026-10-27。本模型接续 `pi-approximation-2026-10-27/INFINITE_RAYS_KAKEYA_BRIDGE.md`。这里的几何恒等式是明确约定下的推导，不声称文献新颖性；未经过 Lean 检验，没有解决 π 的无穷尺度问题。

## 一步得到给定进制的最近余波

令 q≥1 为整数，进制 p=q+1。在这个整数进制的常数数位横线 n/(p−1) 即 n/q。对于 π，本节允许加整数部分：a=3q+n，因此相同斜率写为 a/q。对于小数部分 π−3，应要求数位 0≤n≤q；若 n=q 则代表小数部分的右边界 1，可用下一个整数部分加 0 代表。q=1 即 p=2，整数边界仍可取作最近网格点。

令 R_q=π−⌊qπ⌋/q，0≤R_q<1/q，定义最近网格点距离

    D_q = min(R_q, 1/q−R_q) = ||qπ||/q,

其中 ||t|| 是到最近整数的距离。R_q 是向下取余，而 D_q 允许向下或向上，因此通常不同。最近的 a 由 ⌊qπ+1/2⌋ 给出；π 无理，所以不存在恰好一半的并列。这个表达式完整覆盖一个分母对应的平移，但为了精确判定仍需对 π 的位置有足够精度；它本身不提供无限尺度的统一估计。

## 明确的面积与目标

斜率 a/q 和 π 的无限射线均从原点出发。若移动整条无限射线，非零转角的扫掠面积无限；现将横坐标窗口截成 0≤t≤q，方向由斜率 a/q 连续变化到 π。精确扫出三角形，面积

    A(q,a) = q² |π−a/q| / 2,
    A(q) = min_a A(q,a) = q² D_q / 2 = q ||qπ|| / 2.

注意这是固定横坐标窗口的扫掠面积。若改成固定欧氏针长、平移针或其他运动，必须重新计算，不能把结果混为一谈。

需要的极限是 liminf_{q→∞} A(q)。它为零当且仅当存在 q_j→∞，A(q_j)→0。对于 π 等无理数，该数为正当且仅当存在 C>0，使每个有理数 a/q 满足 |π−a/q|≥C/q²。P2848 的表述满足精确恒等式

    liminf_{n→∞} n|sin n| = 2π liminf_{q→∞} A(q).

证明：一方面，对每个 q，取最邻近 qπ 的整数 n_q。若 q||qπ|| 沿某子列有界，则 |n_q−qπ|=O(1/q)，n_q/q→π，且 sin(n_q)=±sin(n_q−qπ) 与偏差渐近，因此 n_q|sin n_q| 与 πq||qπ|| 渐近。另一方面，若 n|sin n| 沿某子列有界，选最邻近 n/π 的整数 q，则 |n−qπ|=O(1/n)，同时 q→∞、n/q→π。由于 ||qπ||≤|n−qπ|，得到相反的极限不等式。若 liminf 无穷大，同理以有界子列反证；Dirichlet 逼近也保证此处有限。这里没有用上述等价证明其任一值为零。

只能看所有有限 q 的一次 infimum 不够：有限早期点可能特别小。定义尾部下确界 H(Q)=inf_{q≥Q} A(q)，则 lim_{Q→∞}H(Q)=liminf A(q)。而 min_{1≤q≤Q}A(q) 的极限是所有 q 的整体下确界，两者不应混同。

## 同一尺度两个不同方向的排斥

令 x 是任意实数，A_x(q,a)=q²|x−a/q|/2。若 q,s 均处于 [Q,2Q) 且两个有理方向 a/q 与 b/s 不同，整数行列式 |as−bq|≥1，故

    |a/q−b/s| ≥ 1/(qs).

三角不等式及 q/s 在 (1/2,2) 给出

    A_x(q,a)+A_x(s,b)
    ≥ min(q²,s²) |a/q−b/s| / 2
    ≥ min(q,s)/(2 max(q,s)) > 1/4.

所以在一个这样的尺度带内，最多一个**不同的有理方向**能使面积 <1/8。相同有理数的不同非最简分母不应计作不同方向：例如 a/q 和 2a/(2q) 是同一方向，后者面积是前者的四倍。

这个结论描述同尺度小面积方向的稀疏，不能排除某一个候选在无限多个尺度始终存在；因此它不直接决定 π 是否坏逼近。

## 两条夹住目标的相邻方向

若 a/q<x<b/s 且 bq−as=1，设两边的面积分别为 A_x(q,a)、A_x(s,b)，则

    2[(s/q) A_x(q,a) + (q/s) A_x(s,b)] = 1.

证明：令 δ=qx−a>0、ε=b−sx>0，则 sδ+qε=bq−as=1，且 A_x(q,a)=qδ/2、A_x(s,b)=sε/2。

例如 333/106<π<355/113，两分数的行列式为1。它们的面积约为 0.467527867458 和 0.001703155965，代入上式恰为1。接近相同尺度时，两边不能同时很小；但单侧可以极小。因此这个恒等式是面积之间的精确约束，而不是对 π 的统一正下界。

## 如何减少搜索量

对无理目标 x，若 q 的 A(q) 创新低，则 ||qx|| 也比所有更小分母处严格小：否则已有 r<q 使 ||rx||≤||qx||，则 r||rx||<q||qx||。因此面积纪录属于经典的第二类最佳逼近方向，可用连分数收敛分数搜索（初始分母相同时选择最近整数）。这是一种已有工具，不能由前若干项的表现推断部分商的无限性质。参考 [Kansas State University 的数论讲义，第14节](https://www.math.ksu.edu/~cochrane/m706/m706s2018/m706s18notes.pdf)。
