# 有理球覆盖的反证尝试：无限分支剪枝与统一避障规则

2026-11-04。接续“小邻域覆盖后留下的点集，再检验 π 是否属于它”的模型。本轮做解析推导与小规模精确核验，不扫描巨大分母。

**结果范围：没有找到 π 特有的矛盾，没有产生新逼近纪录。** 得到了能一次处理无限后代的区间剪枝、一个全指标的分母比判据，以及一套明确的多尺度避障构造。它们属于经典 Farey／Stern–Brocot／Schmidt 方法的具体重建，不冒称新的丢番图逼近定理。程序、验证范围和未闭合环节均保留。

## 1. 固定对象与量词

仅计最简 p/q，p∈Z、q≥1。对 c>0，

\[
I_c(p/q)=\left(p/q-c/q^2,p/q+c/q^2\right),\quad
K_c=[3,4]\setminus\bigcup_{p/q}I_c(p/q).
\]

于是 π 坏逼近当且仅当存在 c>0 使 π∈K_c；π 非坏逼近当且仅当对每个 c>0，至少一个球包含 π。对无理目标，后一条件迫使分母无界。

有限分母阶段 K_c(Q) 是有限多个闭区间及可能的孤立点，但 K_c=∩_Q K_c(Q) 的归属不能由某个有限阶段的未命中自动决定。c=1 时整数中心的球已覆盖实轴，故必须保留可调的共同系数 c。

二维模型也保留：取0<c<1，在整数点(q,p)处放半径 c/q 的圆盘，实数 x 对应斜率 x 的正射线。圆盘全在正分母半平面，碰球等价于 q²|x−p/q|<c√(1+x²)。坏逼近对应一条能避开全部足够小障碍球的方向；两套 c 相差只依目标方向的常数。

## 2. 相邻分数能整批控制所有后续分母

设 a/b<r/s，b,s>0，且 br−as=1。这样的两个分数围成一个 Farey 括区间 J。

\[
|J|=\frac1{bs}.
\]

任意最简 u/v∈J 都有 v≥b+s。证明：整数 m=rv−su≥1、n=bu−av≥1，且 v=mb+ns。这给出了整个区间内部所有分母的统一门槛。

更强的是整段覆盖：

\[
\boxed{s/b\ge1/c\ \Longrightarrow\ J\subset I_c(a/b)},\qquad
\boxed{b/s\ge1/c\ \Longrightarrow\ J\subset I_c(r/s)}.\tag{1}
\]

因为 J 的长度已不超过相应端点球的半径。这里 J 是开区间，所以等号也允许。一次(1)就能从残留候选方向中剪去中项递归产生的整棵无限区间子树，不必为判定 J 已被覆盖而枚举其后代分母。剪枝针对目标方向区间；若计算完整 K_c，不能据此忽略区间内部那些中心的球伸向 J 外部的部分。

同时用两个端点还能得到更强的空隙判据：

\[
G_c(J)=\left[a/b+c/b^2,\ r/s-c/s^2\right].
\]

它恰是 J 内避开两个端点球的部分（若 G_c(J) 非空，其两个端点落在 J 内）。若左端大于右端，则整个 J 被两球覆盖；若相等，则最多剩一个点。对有理 c，该点为有理数，最终还会被它自己的球覆盖。

所以若无理数 x∈K_c 且 x∈J，必要条件为

\[
\boxed{c\left(\frac bs+\frac sb\right)<1.}\tag{2}
\]

分母相近时可能留有空隙，分母比例过分悬殊时整段被覆盖。这是可直接执行的剪枝规则，不是用面积估计替代点的归属。

## 3. 一个覆盖全部分母的路径判据

从(3/1,4/1)出发，每次插入中项(a+r)/(b+s)，保留包含无理目标 x 的一侧，得到一列 Stern–Brocot 括区间。分母比总记为 max(b/s,s/b)。

**必要方向。** 若 x∈K_c，所有括区间都满足分母比<1/c，且有更强的(2)。这由(1)立即给出。

**充分方向。** 如果某个 M≥1 使全部括区间分母比≤M，则

\[
\boxed{q^2|x-p/q|\ge\frac1{M+1}\quad\text{对所有最简 }p/q.}\tag{3}
\]

证明：对任意 q，取首次两个端点分母都超过 q 的括区间。无理性保证两个端点分母最终都趋无穷。前一步一个分母≤q，另一个≤Mq，故新两个分母都≤(M+1)q。p/q 不在新区间内部，也不等于端点，所以它与 x 之间有某个端点 A/B，且 B≤(M+1)q。整数行列式给

\[
|x-p/q|\ge|A/B-p/q|\ge1/(Bq)\ge1/((M+1)q^2).
\]

因此 π 是否非坏逼近，可以转成它的括区间分母比是否无界。这与经典连分数长同向段的条件相容；它本身不消除那个难点。真正可用的部分是：(1)—(3)把局部整数关系接成了不需要逐项枚举的尾部证书。

## 4. 为什么纯覆盖反证不能直接得到矛盾

剩余点集确实非空。一个完全显式的对照是 x=2+√2：

\[
q^2|x-p/q|>1/4\quad\text{对全部 }p/q,
\qquad x\in K_{1/4}.
\]

当 p/q∈[3,4]，整数范数给

\[
q^2|2+\sqrt2-p/q|
=\frac{|(p-2q)^2-2q^2|}{\sqrt2+p/q-2}>\frac14.
\]

分子是非零整数，分母小于4。区间外，距离已大于1/4。因此仅从整数球的共同几何性质出发，不可能推出“所有方向最终都被任意小 c 的球覆盖”。必须加入 π 的额外结构。

## 5. 明确的多尺度避障构造

现在取 c=1/64。对任意 Q≥1，设闭区间 J 的长度为 ℓ=1/(8Q²)。考虑整个分母块 Q≤q<2Q。

**至多一个危险球碰到 J。** 能碰到的中心都在 J 向两端各扩 c/Q² 的区间内，总长度为5/(32Q²)。而该块内两个不同最简分数的距离严格大于1/(4Q²)，故扩展区间中最多一个中心。

删去这个至多一个开球，所删长度≤2c/Q²=ℓ/4；剩余至多两个闭区间，总长度≥3ℓ/4。因此总能放进两个内部互不相交、各长ℓ/4的闭子区间。它们恰好具有下一层2Q所需的长度。

选取 J_0⊂[3,4]，长度1/8，从 Q=1 迭代，把全部分母分成[1,2)、[2,4)、[4,8)…处理。得到的极限集合非空，且每一点对所有分母都满足 |x−p/q|≥1/(64q²)。两分支等质量分配还给出维数至少1/2：第 n 层有2^n个内部不相交的等长区间ℓ_0·4^(−n)，长度与该层相当的小区间只会碰到有界多个分支，故满足1/2次 Frostman 界。

这是经典避障构造的一套显式常数。它证明这个几何模型不需要遍历到无穷，也能对极限点给出全指标保证。

**但它不是 π 的证明。** 每层为统一尺度会额外丢掉一些未被覆盖的点；构造出的树只是 K_c 的子集。π 离开这棵人为选择的树，不能推出 π 被覆盖。若要针对 π，必须证明每次选择都能保留 π，或直接给出一个包含 π 的具体危险球。

## 6. 有限精度区间的准确局限

任何非退化区间 J、任何 Q，都含有分母≥Q的最简有理数，所以 J 必与后续覆盖球相交。因此不能拿一个有限宽的 π 包围区间，整体认证所有未来分母都不碰它。

此外任意非空有理区间都同时含坏逼近数和非坏逼近数：在其中取[M/N,(M+1)/N]，则

- (M+√2−1)/N 为二次坏逼近数。整数范数直接给一个常数1/(4N)。
- (M+L)/N 为非坏逼近数，其中 L=Σ_{n≥1}10^(−n!)。截断到 n!，取分母Q_n=N10^(n!)，有 Q_n²误差≤2N·10^(−(n−1)n!)→0；约分只会改善此上界。

所以任何有限精度的目标区间本身不能区分两类。这里限制的是“只使用一个区间包围证书”的信息模型，不是所有 π 证明或计算方法的不可能性定理。

## 8. 本轮反证尝试停在哪里

假设 π∈K_c，确实能推出其全部括区间端点分母比有界。要导出矛盾，还需要从 π 的原生积分、级数、周期或整数递推中推出这些比例不可能一直有界。本轮未得到这条 π 特定命题。

已完成的工具改变了尾部处理方式：用整段剪枝与同一条层间规则处理无限分母，而不是把有限扫描当成无限证明。下一步应把 π 的精确结构接到分支选择上；不继续单纯扩大扫描范围来冒充理论闭合。
