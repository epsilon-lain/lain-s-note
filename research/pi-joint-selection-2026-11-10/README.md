# 联合选择权重与 π 候选：同条件对照与完备选择

2026-11-10。接续 [π² 小范数构造](../pi-small-norm-construction-2026-11-04/README.md)，源版本固定为 `88c331c410290c5eb915776ecd2415bffff20dc0`。

**本轮执行了“不要先只保留最小辅助分母，而把权重和最终 π 候选联合选择”的建议。原条件下没有改善实际质量；进一步得到当前误差证书的完备选择方法。没有新 π 逼近纪录，也没有无限成功族。**

这里始终用完全约分的 `p/q`，`q>0`，评价量为 `Q=q²|π−p/q|`。当前构造目标是使 Q 沿无界分母子序列趋零，即尝试证明 π 非坏逼近；本轮没有决定这个问题。

## 1. 原来的选源步骤确实可比较，但本轮没有带来新分数

旧程序先生成一批非负、互素的整数权重，只保留既约辅助分母 B 最小的源 A/B，然后搜索小范数解 `h=Bp²−Aq²`。

新的 `experiment.py` 保留**同一批权重的全部不同源**，使用完全相同的两个预算 `H=min(25,B)` 与 `H=floor(sqrt(B))`，以及同一条件 `|h|≤H`、`Bq²Δ≤H`。其中 Δ 是相邻 Apéry π² 源的区间宽度。π 区间只在候选生成后评分。

| 1≤n≤128，同权重池、同预算 | 原最小 B 方法 | 联合选择 |
|---|---:|---:|
| 检查的源数 | 128 | 25,029 |
| 检查的根式收敛分数条目 | 12,231 | 2,820,622 |
| 通过预算的记录数，含重复分数 | 6 | 9 |
| 不同的最终分数 | 3、22/7、355/113 | 3、22/7、355/113 |
| 最大成功源指标 n | 4 | 4 |
| 相对原方法改善实际 Q 的指标数 | — | 0 |

仅 n=1 的同一分数 3/1 得到更紧的上界；这没有改变真实 Q。因此，本次数据不支持“只延后最小 B 筛选就会改善逼近”的期待。这个结论只针对列出的权重池、预算和指标范围，不排除别的构造。

## 2. 无穷多权重可以在这个证书下完整消去

设相邻源包围 π² 的区间为 `[L,U]`，`Δ=U−L`。任意非负整数权重给出其中的有理源 R=A/B；反过来，**区间中的每个有理数都能由这样的权重表示**，并可精确重建全部权重和实际 gcd。

原来的三角不等式证书为

\[
Q<C(R,p,q):=\frac{|Bp^2-Aq^2|/B+q^2\Delta}{6},
\qquad 3\le p/q\le4.
\]

于是，对固定既约 p/q，所有权重上的最优证书恰为

\[
\boxed{C_*(p,q)=\frac{q^2}{6}\left[\Delta+
\operatorname{dist}\big((p/q)^2,[L,U]\big)\right].}
\]

`dist` 表示点到闭区间的距离：在区间内为零，在区间外为到最近端点的距离。最优源可直接取最近端点；若平方落在区间内，则取 `R=p²/q²`。

用 3/1 给出的初始上界 `C0=(U−9)/6≤1/6`，所有可能优于它的分数必满足

\[
q\le\left\lfloor\sqrt{6C_0/\Delta}\right\rfloor.
\]

而且它们是两个端点平方根的普通连分数收敛分数。故只需检查有限的端点候选列表，就能求出**此固定源区间、此证书、全部非负权重及全部既约 p/q∈[3,4] 上的全局最小值**。实际程序保留两列候选的并集；证明还表明每个有竞争力的分数属于两列各自的列表。

这是本轮最有用的结果：把任意挑权重改成了有完整性证明的选择。它使用标准的整数线性代数、区间距离与 Legendre 判据；不声明文献首创，也不等于求出了真实 Q 在全部有理数上的最小值。完整证明与权重成本见 [THEORY.md](THEORY.md)。

## 3. 放开固定 H 预算后的独立实验

`full_cone.py` 是另一组实验：**不再施加原来的两个 H 预算**，直接最小化上述证书。因此下表不能当成第 1 节同条件对照的收益。

对 `1≤n≤256` 的每个区间求证书最优值，共检查 134,271 条端点收敛分数记录，按每个区间去重后合计 67,149 个候选。最优分数发生变化的位置是：

| 首次选中的源指标 n | 最优分数 |
|---:|---|
| 1 | 3/1 |
| 2 | 22/7 |
| 3 | 355/113 |
| 150 | 分母为 155 位的既有好逼近分数 |
| 209 | 分母为 216 位的既有好逼近分数 |

最后一个分数的实际质量严格满足

\[
0.000048130561246289404628<Q<0.000048130561246289404629.
\]

它与仓库此前覆盖树实验的已知结果相同。第 256 项的最优证书约为 `0.000050402205874832132225…`。完整整数、权重和有理证书均可从数据与程序重建。

256 个最优结果中，255 个使用原区间端点；只有 n=3 使用内部的平方源 `R=(355/113)²`。该情况的辅助分母恰为 `113²`，小范数为零来自已选分数的平方，不能把这个零单独当成生成好逼近的新机制。

理论还给出一个更紧的区间证书推论：若将统一 Δ 改成源位置相关的最大误差，那么全部权重上的最优值可直接由 L、U 算出，中点源总能达到它。这一推论在 THEORY.md 单独证明；上面的数值实验仍使用统一 Δ，未把更紧证书的潜在收益算入结果。

## 4. 验证与复现

在仓库中运行，只需 Python 3 标准库：

```sh
cd research/pi-joint-selection-2026-11-10
python3 experiment.py
python3 verify.py
python3 full_cone.py
python3 full_cone_verify.py
```

生成器复用旧目录中的精确源与根式递推。独立验证器用二项式和及 Casoratian 累加重建源，用二进有理平方根区间抽取连分数，并用独立的定向 Taylor 区间验证 π² 包围和实际 Q。完整同池扫描、全区间证书最优值与原始权重/gcd 均检查；小指标另用逐个 p,q 枚举对照，并检查有理平方端点的有限连分数分支。

`results.json` / `verification.json` 保存同池对照；`full_cone_results.json` / `full_cone_verification.json` 保存全权重证书选择及核验。为避免重复存储巨型整数，后者用每个源指标的完整精确记录摘要、不同分数表和关键完整见证保存；验证器会重建每条精确记录并检查摘要。`manifest.json` 固定本轮文件与依赖的内容指纹。

## 5. 本轮之后仍须解决什么

这里允许的正权重已经能表达区间中的全部有理源。继续增加这种表示的自由度，不能超越已求出的证书最优值。此结论的边界是**同一源区间与同一证书**；它不排除利用有符号余项之间的额外关系、更强的 π 专属递推或不同构造。

下一项真正的构造任务仍是：由 π 的精确结构强迫上述最优值沿无界指标趋零，或构造超出这个区间证书信息的新关系。本轮完成了选择方法和有限核验，没有证明这种无限机制。
