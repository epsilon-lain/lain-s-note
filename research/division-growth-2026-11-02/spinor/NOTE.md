# 从共同成长到无 π 数字输入的有理圆积分

本节把用户的共同成长/除法想法落实为一个可计算接口。使用的是标准有理圆参数化和反正切求导，不主张这些基础恒等式首创。基础公式可核对 [DLMF 4.24.9](https://dlmf.nist.gov/4.24.E9)。

## 1. 两条整数多项式决定同一个圆上的运动

取 P,Q∈Z[t]，在 [0,1] 上满足

\[
P>0,\qquad Q(0)=0,\qquad Q(1)=P(1).
\]

记

\[
D=P^2+Q^2,\quad W=PQ'-QP',\quad
X=\frac{P^2-Q^2}{D},\quad Y=\frac{2PQ}{D}.
\]

于是 X²+Y²=1、(X(0),Y(0))=(1,0)、(X(1),Y(1))=(0,1)，并且

\[
XY'-YX'=\frac{2W}{D}.
\]

由于 P 始终为正，arctan(Q/P) 给出连续的实角分支，故

\[
\boxed{\pi=4\int_0^1\frac{PQ'-QP'}{P^2+Q^2}\,dt.}
\]

构造条件只有整数系数、正性和端点相容，不需要输入 π 的小数或预先选好的优良分数。若 W≥0，角度单调，参数曲线沿圆从 (1,0) 走到 (0,1)，积分同时给出四分之一圆的真实弧长。若 W 变号，该积分是有向角变化，不能把它说成总路程。

例子 P=1+t²、Q=2t 给出

\[
\pi=8\int_0^1\frac{1-t^2}{1+6t^2+t^4}\,dt.
\]

这是标准 arctan 恒等式的一种重参数化；它改变了采样核，而不是直接证明有理逼近更优。

一个可穷举的整数入口是

\[
P=1+t^2 A(t)^2,\qquad Q=tP(1)+t(1-t)B(t),
\quad A,B\in\mathbb Z[t].
\]

P≥1，全部端点条件自动满足。W 的符号可以另作认证，角积分恒等式本身不要求 W 非负。

## 2. 共同成长完全消失，真正的设计变量是方向

令 C 为区间上非零的 C¹ 实函数。将 (P,Q) 同时替换为 (CP,CQ)，直接展开得

\[
\widetilde W=C^2W,\qquad \widetilde D=C^2D.
\]

C' 项精确相消。X、Y 和 W/D 全部不变；这个结论允许 C 任意变化，不局限于常数缩放。若 C 有零点，原表达式在该点未定义；已知共同因子后约去才给出可去延拓。

因此，只给两条成长函数乘同一个更复杂的波，不会改变这一读数，也不会凭空改善最终有理数。有效改造必须改变 Q/P，即两条函数的相对方向，同时保住端点。上面的 A、B 正是可以改变方向的真实参数。

对整数多项式而言，可以先取 gcd(P,Q)，约去公共多项式因子。这会降低实现费用；由于积分核原本就相等，不计作新的逼近收益。

## 3. 每个有理采样点都有可核查的整数成本

假定 deg P,deg Q≤d，d≥1；全部系数绝对值≤H，H≥1。最高项的反对称抵消给出

\[
\deg W\le2d-2,\qquad
\|W\|_\infty\le2d(d+1)H^2,\qquad
\|D\|_\infty\le2(d+1)H^2.
\]

取既约采样点 t=p/q∈[0,1]，q>0，定义整数

\[
\widehat P=q^dP(p/q),\quad \widehat Q=q^dQ(p/q),\quad
\widehat W=q^{2d-2}W(p/q).
\]

则核的精确有理读数为

\[
4\frac{W(p/q)}{D(p/q)}
=\frac{4q^2\widehat W}{\widehat P^2+\widehat Q^2}.
\]

实际分母是右边完成 gcd 约分后的分母。令 M=max(|p|,q)，其上界为

\[
\operatorname{den}\left(4W(p/q)/D(p/q)\right)
\le2(d+1)^2H^2M^{2d}.
\]

加权求和后，还要支付不同采样分母的合并成本；上式不是整个求积结果分母的上界。

## 4. 与主目标相接的可执行任务

用整系数 A、B 生成不同方向，精确约去 gcd(P,Q)，认证端点和 P>0；然后在相同有理节点上求积，并用共同误差消去组合。评分必须使用最终既约分母 q 与 q²|π−p/q|，同时记录参数次数、高度和节点数。不能只比较积分误差。

`verify_spinor.py` 通过符号恒等式、整数实例和完整既约分母核查这个接口。它不宣称上面的重参数化已给出 π 新纪录，也不证明目标质量趋零。
