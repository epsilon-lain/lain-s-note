# 新构造试验：用低阶角逼近预设多区间约分

2026-11-04。起点是仓库 `98a2b9fa0601da361cc76744c7c601b6d4b2af69`。读取最新的研究方向、双角相消/29进整除、周期比证书及物理反馈后，本轮另做系数预设计的耦合构造。

**本轮没有找到爆破解或新π逼近纪录。** 得到一个可以迁移的整除设计规则，并实际生成、约分和严格评分了新候选。当前实现没有联合质量收益，以下把有效规则与实际成本一起保留。

## 1. 构造改变在哪里

旧双角路线分别产生角逼近，再研究合并时有哪些公因子。这里先选择整数系数，让若干**低阶有理逼近的完整加权和精确为零**；这些零关系会强制高阶候选在对应素数区间里消去分母。

令r_n(c)为由整数递推生成的反正切连分数读数。对参数c=s/t，定义归一化生成函数

\[
\sum_{n\ge0}u_nz^n=(1-2tz-s^2z^2)^{-1/2}.
\]

证明了一个残量降阶公式：写n=ap+b，若p为奇素数、p²>n、p∤st，且u_a、u_b模p非零，则

\[
\boxed{p\,r_n(c)\equiv
\left(\frac{-1}p\right)r_{\lfloor n/p\rfloor}(c)\pmod p.}
\]

由此，预先安排ΣC_jr_a(c_j)=0，a=1,…,H，便能在保留π周期的同时，让n/(H+1)<p≤n中的**合格素数**不再整除最终既约分母。参数分母、π归一化系数及u的零点都有明确例外条件；未证明例外素数很少，也未证明整个素数区间无例外。

完整推导与所有前提见 [THEORY.md](THEORY.md)。这是本项目的系数设计与推导，不声明经典连分数、Frobenius或所述同余的文献首创性。

## 2. 一个显式的三角版本

使用既有角关系arctan(2/5)+arctan(3/7)=π/4，再加入第三个角arctan1。系数可预先取

\[
35\cdot\frac25+35\cdot\frac37-29\cdot1=0,
\]

于是新读数为

\[
\boxed{P_n=\frac23\left[
35r_n(2/5)+35r_n(3/7)-29r_n(1)\right].}
\]

它确实趋于π，并在上述条件下消去首个素数区间。另已构造四、五、六个角的版本，分别预消去前2、3、4个低阶残量。

这些不是给原分子分母一起乘常数：系数改变了真正的角组合与输出分数。全部系数先本原化，再计算完整候选的实际gcd。

## 3. 实际约分成立，完整质量仍恶化

采用质量Q(p/q)=q²|π−p/q|，q始终为完全约分后的正分母。没有用构造阶数代替q，也没有只报告额外公因子。

|---:|---:|---:|---:|---:|---:|
|1|3|6|78|833|797|
|2|4|24|77|1355|1318|
|3|5|55|76|1880|1849|

位长全部指二进制。H=1、n=80时，41、43、47、53、59、61、67、71、73、79十个素数全部通过条件，并从最终分母消失；但新q仍有833位，原双角基线q为766位。新增通道与递推系数的大因子已经超过这部分收益。

306个同步候选和237个异步候选，无一改善各自原双角基线的真实质量；全部逊于355/113。异步版本使用固定有理阶数网格，不能把它当成已证明的无限强相消选择律。

为修正各角独立计算的分母乘积成本，又做了5个三函数共享多项式分母的同时Padé对照。它们的Q也全部大于1。该共享分母版本有不同的余项结构，未把上面的残量降阶定理未经证明地套过去。

## 4. 真正留下的算术对象已经能写清楚

令W_n=2^nu_n∈Z、L_n=lcm(1,…,n)，K为π周期的整数归一化系数。新族的实际分母满足

\[
\boxed{q_n\mid K L_n\operatorname{lcm}_j|W_n(c_j)|.}
\]

因此，q中所有大于n的素因子都来自K或W_n。低阶残量零关系可以取消多段调和分母，但没有自动使各W_n共享分母。这比“公因子还不够大”更具体：新构造下一步必须控制这些归一化递推系数，继续增加消去区间会同时推高角数、系数高度和K。

本轮的目标是构造成功，未把上述失败对照当成π坏逼近性或旧固定族的排除成果。也没有证明所有参数的类似构造都不可能成功。

## 5. 高斯整数幂的前置对照

先试过同一高斯整数的幂，希望共享范数能自动安排整数结构。由(2+i)的第1、6、7次幂得到

\[
\pi=\arctan\frac12+6\arctan\frac{44}{117}
+5\arctan\frac{29}{278}.
\]

三条有理方向的原始范数分别是5、5⁶、5⁷，且各坐标对本原。对它们作一个同步Euler线性形式匹配，得到候选

\[
\frac{23040475932864512}{7333971781828125},\quad
\operatorname{den}=3\cdot5^6\cdot7\cdot29833\cdot749209,
\]

其Q介于10²⁶与10²⁷。范数只有5的幂，并未阻止新大素因子进入最终分母。这是一个具体失败对照，不是关于所有高斯整数构造的否定定理。相应方程、权重、完整分母和独立重建均保存在 `orbit_control_results.json`。

具体地，令F_j(x)=h_jΣb_nz_jⁿxⁿ，h_j=A_jB_j/(A_j²+B_j²)、z_j=B_j²/(A_j²+B_j²)、b_n=4ⁿ(n!)²/(2n+1)!，有F_j(1)=arctan(B_j/A_j)。选择一次权重L_j(x)，使ΣL_j(1)=Σk_jL_j(1)=0、Σw_jL_j(1)=−1，并令ΣL_jF_j的一至三次系数为零。其常数项就是上面的有理候选；π周期由端点条件保留，没有预先输入目标分数。

高斯整数与反正切恒等式的经典背景见Calcut的[作者PDF](https://isis2.cc.oberlin.edu/faculty/jcalcut/gausspi.pdf)，本轮读取了引言及高斯整数基础部分；没有独立审核该文全部定理。单角连分数使用[NIST DLMF 4.25.4](https://dlmf.nist.gov/4.25.E4)。这些基础工具均不作为本项目首创。
