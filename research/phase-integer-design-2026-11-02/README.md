# 误差同步与预设约分：全指标净收益、固定相位整数格

2026-11-02。接续用户要求“设计相对方向，使多个读数的误差同步消去，并让它们共享可约分的整数结构”。本轮完成一般整数费用接口、一个全指标相对质量收益定理、可预设公因子的方向变形发生器，并实际测试高阶与更快通道。没有新的 π 逼近纪录，也没有构造出绝对质量趋零的无限序列。

基础使用经典 Aitken 变换、相位求导、Bézout 与有理积分；不把这些工具在本模型中的实现当作基础理论首创。Aitken 的标准式可对照 [DLMF 3.9.7](https://dlmf.nist.gov/3.9.E7)。

## 1. 对每个指标都有效的真实质量收益

定义

\[
S_m=\sum_{j=0}^{m-1}\frac{(-1)^j}{2j+1},\quad
U_m=4S_m,\quad V_m=U_m-\frac{(-1)^{m-1}}m,\quad m\ge1.
\]

V_m 等于 U_(m−1)、U_m、U_(m+1) 的 Aitken 商，因此修正不是填入 π 的已知误差。令 q_m、r_m 是 U_m、V_m 的**实际既约分母**，d_m=gcd(m,q_m)，并定义 Q(R)=den(R)²|π−R|。证明了

\[
\boxed{\frac{Q(V_m)}{Q(U_m)}<\frac1{4d_m^2}\le\frac14
\qquad(\text{所有 }m\ge1).}
\]

这是误差和实际分母共同收费后的结论，不是只提高误差阶数。证明分为两步：

- 正积分给出原误差 1/m−δ_m、校正误差 δ_m，且 m≥2 时 δ_m<1/[m(4m²+1)]。
- 约分后分母满足 r_m/q_m≤m/gcd(m,q_m)。两式相乘得到上面的净收益；m=1单独核查。

常数1/4还是全指标的最优统一常数：在 m=2^r 上，r_m=mq_m，且 δ_m∼1/(4m³)，实际质量比趋于1/4。完整证明及1000个一般指标的独立回放见 [分母与误差证明](denominator/NOTE.md)。

## 2. 奇素数幂链：校正根本不增加分母

令 m=p^r，p为任意奇素数。在奇分母 1,3,…,2m−1 中，只有中央项 m 含 p^r，且没有 p^(r+1) 的倍数。因此 m 整除原来的实际 q_m，校正 1/m 的全部分母已经存在。进一步得到精确分类：

\[
\boxed{r_m=\begin{cases}
q_m/3,&m=3^{2k},\ k\ge1,\\
q_m,&\text{其余奇素数幂}.
\end{cases}}
\]

于是整条固定奇素数链都有 Q(V_m)/Q(U_m)<1/(4m²)，并非从有限数据推测。例外的3偶数次幂再有额外分母收益。另有独立证明和 m≤2001 的323个奇素数幂重建，见 [独立审阅](gaussian/AUDIT_COMMON_DENOMINATOR.md)。

**这个样机用于验证“消误差且不增分母”确实可以同时做到，不作为最终爆破解。** 它的原分母仍然很大：区间(m,2m)内的每个奇素数都只出现在一项中，不能被1/m校正消掉，故这些素数的乘积整除 r_m。素数定理给出 ln r_m≥m+o(m)，而 δ_m≥B(2m,3)∼1/(4m³)，所以本样机 Q(V_m) 仍趋于无穷。这里仅用两行账明确样机的用途；不继续扩大该慢族的排除研究。素数定理背景见 [DLMF 27.12](https://dlmf.nist.gov/27.12)。

可迁移的是：先利用生成规律消去大公因子，再认证误差；不是继续追逐这个慢级数本身。

## 3. 相对方向可以改，采样分母可以固定

取标准有理圆 r(t)，把它旋转 H(t)/2，其中 H(0)=H(1)=0。角读数的核变为

\[
f_H(t)=\frac4{1+t^2}+H'(t),\qquad\int_0^1f_H(t)\,dt=\pi.
\]

令 H=Σc_jψ_j，ψ_j 为固定的零端点有理基函数，c_j 为整数。固定有理求积节点后，所有候选都具有同一个原始分母：

\[
\boxed{R_c=\frac{A+\sum_jB_jc_j}{M}.}
\]

方向参数只改变整数分子，M不随参数变化。预设约分因子 m|M 有整数解的充要条件为 gcd(m,B₁,…,B_s)|A；可解时存在 |c_j|≤floor[m/(2d)] 的解，d=gcd(m,B₁,…,B_s)。解集是指数m/d的整数格陪集，仍可在其中选择误差。这是生成前的公因子保证，附有系数高度费用。

采用2段梯形的具体基时，候选为 (620+9c₁−13c₂)/200。预设m=5、|c_i|≤4、要求约分后q>10，脚本只用端点误差预测377/120选择参数，唯一选出(c₁,c₂)=(4,2)：

\[
\frac{31}{10}\longrightarrow\frac{63}{20},\qquad
q:10\to20,\qquad Q:4.159265\ldots\to3.362939\ldots.
\]

这只是一个很小的联合正例，仍逊于22/7和355/113。原始gcd从基线20变成候选10，不能说候选比基线有更大gcd；正确说法是预设约分确已实现，误差缩小抵过了分母增长。

选择在整个粗目标区间 [377/120−1/1000,377/120+1/1000] 内稳定，区间内保证质量收益至少61/56；只用Machin级数3+1项即可认证π在此区间。候选脚本生成和选择不读取π小数，但不将本轮研究历史称为“盲发现”。

相位曲线的坐标通常非代数，角核仍是有理函数；这与整系数spinor P,Q的有理曲线子类有区别。详见 [方向变形与固定分母](deformation/NOTE.md)、[一般费用与有高度界的同余解](GCD_DESIGN.md)。

## 4. 已运行的其它构造与对照

- 正余项的Beta展开产生229个高阶候选：181个相对一阶改善、48个恶化。最好绝对质量只恢复22/7。高阶不自动保留一阶的分母定理，均按真实q评分。
- Pell参数使三个角相位共享高斯范数D、2D、2D²，归一化尾项有显式同步界，且首阶整数消去权重差恰含D。336个预定候选中仅1个胜过自身基线，全部未达到已有优良基准，因此不继续扩充这套未经改造的权重扫描。见 [高斯范数对照](gaussian/NOTE.md)。
- 快速Machin两角级数已作10组迁移对照：先按已知项比在每个通道内消去，再合成，均优于先混合后盲消去。它避免支付混合误差制造的大差分因子；绝对质量仍差，完整记录在 `denominator/fast_channels.json`。
- 固定截断的正有理积分证书直接评分δ_m：相对半宽≤2/3^(K+1)，与m无关，不必先计算π小数；生成S_m及实际q的费用另外保留。见 [直接误差证书](certificate/NOTE.md)。
