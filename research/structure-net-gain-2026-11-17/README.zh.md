# 有费用的结构优势：和差坐标与精确傅里叶卷积

2026-11-17。用户要求寻找“计入新增信息、表示转换与还原后仍有净优势”的具体例子。本轮给出两个成熟方法的可复现实例，重新声明费用并核对实际代码。不是新颖性声明，不是本机 Yohaku 新阶段，也没有得到 AC 比赛新路线。

最直接的结论：**换到合适结构后，转换与还原的执行费用可以完整计入，仍严格少于一个明确的直接算法。** 方法发现／学习、运行时间、内存等费用不能无单位地混加；下面分别说明哪些已经计入，哪些需另记。

## 一、最小清楚例子：把两个耦合量换成和与差

输入是任意四个数 a、b、u、v，矩阵的形状由任务规定：

$$A=\begin{pmatrix}a&b\\b&a\end{pmatrix},\qquad x=\binom uv.$$

任务是输出 A 的八次作用后的普通坐标，即 A⁸x。八次是固定公开任务参数，不把第八次结果或特征值免费给定。一般证明适用于实数，以及任何特征不为2的域。

### 结构为什么能解决问题

一次原操作为 (u,v)→(au+bv,bu+av)。改看

$$s=u+v,\quad d=u-v,\quad p=a+b,\quad q=a-b,$$

则一次作用变成 (s,d)→(ps,qd)。两个方向不再相互混合。于是八次作用可直接得到

$$r=p^8s,\quad t=q^8d,\qquad u_{\rm out}=(r+t)/2,\quad v_{\rm out}=(r-t)/2.$$

p⁸、q⁸各用三次平方得到。零特征值也允许；没有除以输入的操作。

严格地，令 T=[[1,1],[1,−1]]，则 TAT⁻¹=diag(a+b,a−b)，而 T⁻¹=(1/2)T。两个输入坐标和两个参数的变换均为双射，没有丢失信息，也没有加入输入相关的辅助位。还原后的输出就是原问题的 u、v 坐标。

这还可以同时处理整个矩阵族 A(a,b)：所有成员在同一个 T 下对角化。对不同矩阵的连续作用也能沿用同一坐标，结构并非只对一个已知答案生效。

### 完整的标量执行与外部 I/O 账本

两种算法都允许标量加、减、乘、除，每次收费1；读取一个外部输入、写回一个输出也各收费1。每条标量指令中的寄存器读取已包含在其费用内。循环可展开为固定直线程序，本表不另计 Python 控制／对象管理开销。常数2由1+1现场构造并收费，没有隐藏免费的恢复步骤。

| 环节 | 直接做8轮 | 和差结构路线 |
| --- | ---: | ---: |
| 读取 a、b、u、v | 4 | 4 |
| 构造常数2 | 0 | 1 |
| 参数与输入转换：p、q、s、d | 0 | 4 |
| 8轮直接矩阵作用：每轮4乘2加 | 48 | 0 |
| p、q各平方3次 | 0 | 6 |
| 与 s、d相乘 | 0 | 2 |
| 还原：2次加减、2次除法 | 0 | 4 |
| 写回两个原坐标输出 | 2 | 2 |
| **总计** | **54** | **23** |

因此在声明的计价下，单次严格节省31。仅算标量算术则为48→17。除法是两边都允许的一个原语；有限域检查器用幂求逆来实现它，并不把 Python 内部实现误称一次底层整数运算。

如果输入不是已参数化的矩阵，而是普通2×2矩阵的4个条目与2维向量，可以先付2次相等检查，判断两个对角条目和两个非对角条目是否分别相同。对命中该形状的输入，若比较也收费1，则直接算法为6读+48算术+2写=56，结构算法为6读+2检查+17算术+2写=27。未命中可以回退直接算法；此处没有声称所有矩阵都能如此处理。

### 复现与比较边界

[check_matrix.py](check_matrix.py)实际穷举 F₁₇ 上全部17⁴=83,521个输入四元组，两个输出逐项相等，逐项操作计数恒为54／23。完整结果在 [matrix-checks.json](matrix-checks.json)。一般正确性来自上面的代数恒等式，不把一个有限域枚举外推为实数证明。

54是所列直接算法的精确费用，**不是对全部标量算法的最优下界**。原坐标下允许任意中间计算的程序，本来就能内部实现和差变换。这个例子证明学会结构、采用新算法有收益，不证明“仅由坐标名字就产生不同的普适计算能力”。

可选的严格受限基线是：状态只允许复制和做 z→Az，且每次作用按固定6条算术指令实现。实数上取 A=2I、x=(1,0)，少于8次这样的状态操作不能得到 A⁸x，因此8次在这个受限体系中最优。不能把此受限下界移植到任意标量电路。若在 F₁₇ 内使用此见证，应改用 A=3I，因为2的八次幂已经等于1。

### 同一结构支持变化的操作链

对于给定 m 个不同的 A(aᵢ,bᵢ)，求 Aₘ…A₁x：直接路线用6m条算术；在和差坐标下，输入转换2条，每个矩阵转换2条并做2次分量乘法，最后恢复4条、构造常数2再1条，共4m+7条。共同输入／输出费用为2m+4。因此当 m≥4 时同样有净执行节省，差值2m−7。

这个延伸来自同一逐步恒等式，经独立解析审阅；本轮没有额外枚举所有变化矩阵链。它说明即便不跳过原来的作用轮数，也可通过让操作变为分量独立来降低费用。

## 二、更大规模例子：有限域傅里叶变换计算循环卷积

为避免浮点精度问题，输入为模257的两条 n 项序列，n取16、32或64。任务始终是输出普通系数序列

$$c_k=\sum_{j=0}^{n-1}a_j b_{(k-j)\bmod n}\pmod {257}.$$

直接逐项算每个输出，花 n²次乘法及n(n−1)次加法。另一条路线先把两份输入做可逆变换，在新表示下逐坐标相乘，再完整逆变换回普通输出。其转换不是免费宏。

### 可逆性与结构保持

构造3，连续平方验证3¹²⁸=−1、3²⁵⁶=1；所以3的乘法阶为256。令 ω=3^(256/n)，则其阶为n。定义

$$\widehat a_r=\sum_j a_j\omega^{jr}.$$

代入卷积式并交换有限和，得到 ĉᵣ=âᵣb̂ᵣ。逆变换是乘以 n⁻¹ 的负指数变换：单位根幂和在零指数时为n、其他指数时为0，故它严格恢复每个原系数。没有符号分支、额外对象信息或浮点舍入。

### 所有场内转换、准备与还原算术均收费

此例每次有限域加、减、乘各收费1，约减包含在该域运算内；即便乘0或1也计费。另将内存、索引、控制、比较、I/O和方法获得费用独立记账，**不把下面总数称为全部机器成本或墙钟加速**。正式输入已经是标准域元素；检查器对负整数测试的输入适配器不在账内。

每个蝶形用1乘2加减；一个 n 项变换有(n/2)log₂n个蝶形。两次正变换和一次逆变换都计入。逐坐标乘法和逆归一化各n次乘法。每次求解都重新构造并验证所用根、构造幂表和逆元，不依赖免费的预计算缓存：

- 从1构造3：2次加法。
- 完整平方梯验证阶并供应根：8次乘法。
- 用n²⁵⁵算n⁻¹：14次乘法。
- 完整幂表：n−2次乘法；逆根幂用同表反向索引。

总乘法数为(3/2)n log₂n+3n+20，加减数为3n log₂n+2，合计(9/2)n log₂n+3n+22。

| n | 直接算法算术 | 含全部准备与正逆变换的算术 | 节省 |
| ---: | ---: | ---: | ---: |
| 16 | 496 | 358 | 138 |
| 32 | 2016 | 838 | 1178 |
| 64 | 8128 | 1942 | 6186 |

在每个规模，乘法数和加减总数都分别下降，所以这不是靠把复杂乘法硬算得比加法更便宜。两种表示都保有相同输入信息；当前递归代码的峰值存储为O(n)，累计分配为O(n log n)，这些内存动作未收费，不能据表推得总运行时间同倍率提升。

[ntt/check_ntt.py](ntt/check_ntt.py)已实际运行：每个规模9组结构例子与100组固定种子的随机例子；n=16再检查全部256个标准基向量对，共583对输入，全都逐项相等且计数符合公式。[实际结果](ntt/checks.json)。对n=16，两种实现的双线性结合全部基对检查认证该固定双线性映射；n=32、64不称输入全枚举。一般证明来自卷积和单位根恒等式。

这仍然是两种明确算法的比较，不是任意原表示算法的下界。固定域F₂₅₇至多支持256长的这类二进制变换；若讨论无界规模，须另登记更大域与根的获得费用。

## 三、新结构的知识费用如何记

以上两个例子需要增加的是与输入无关的通用方法，不是额外告知每个输入的答案或符号。相同方法可跨独立输入复用，与上一轮每个对象分别发送相对符号的辅助消息不同。

若额外获得、装载、核验方法的一次性费用为K，并已经用**同一明确单位**计价，则对第一个例子复用Q次的净节省为31Q−K，严格获利条件为Q>K/31。K已知时可给精确摊销阈值。若两种程序一开始都已提供，所比较的是执行费，额外K为0。

本轮没有测量AI发现方法的token、一般证明发现时间或任意编译器费用，也没有把它们当作零后声称“全部成本都获利”。若它们的单位不同，先保留算术、I/O、存储、知识描述长度、学习时间等成本向量；确定权重后才能提出单个总优势值。

## 四、对研究主线的作用

这两个例子给出同一种可以尝试推广的结构：寻找一个对任务族适用的可逆表示，使原来互相耦合的作用变成独立／稀疏作用，转换与恢复只付有限费用，之后靠更便宜的操作或多次复用获得净收益。

这与“完整双射搬运不自动降低对应原语成本”不矛盾：这里没有将整套标量电路仅改名，而是发现原作用在特定表示下的更便宜实现，并计算真实展开的标量运算。优势属于具体目标、算法、允许知识与计价。
