# 进制小数的长方形积分与非负波差

2026-10-27。将用户提出的进制尺度长方形求和写为普通积分，并检验不使用正负抵消的面积能否表示同一无穷逼近问题。以下初等推导不宣称数学文献首创；未运行 Lean，未证明 P2848。

## 1. 数位长方形

取整数进制 p≥3，q=p−1，目标小数部分 x∈(0,1)。用逐位取整规则取得数字 d₁,d₂,…∈{0,…,q}，因而 x=Σⱼ≥1 dⱼ p⁻ʲ。π 取 x=π−3，整数部分3单独保留。

把 (0,1] 划为连续尺度壳：Iⱼ=(p⁻ʲ,p^(1−j)]，j≥1。第 j 层的宽度是 q p⁻ʲ，定义数位高度函数 h(t)=dⱼ/q（t∈Iⱼ），另设 h(0)=0。于是第 j 层长方形的面积为 dⱼ p⁻ʲ，且

    x = ∫₀¹ h(t) dt = Σⱼ≥1 dⱼ p⁻ʲ。

这是通常意义下的定积分：截到第 K 层后，剩余区间长度 p⁻ᴷ，且 0≤h≤1，故面积尾项至多 p⁻ᴷ。固定 p 时 1/p 是普通正数，而 p⁻ʲ 随 j→∞ 趋零；无须使用非标准无穷小。

放大 t↦pt 是 I_{j+1} 到 I_j 的双射；它放大的是空间区间，不单独提供整串数位的可逆左移。若采用贪心展开（对终止小数选末尾全零），x 与由该展开得到的分层函数一一对应；允许任意重复 (p−1) 尾巴则小数表示可能不唯一。

恒定数位 n 对应常数高度 c=n/q，0≤n≤q；水平线下总面积为 c。n=q 的恒定展开表示1，是端点情况；该函数虽可用于面积比较，并非 x∈(0,1) 的贪心展开。

## 2. 非负面积

对整数 0≤n≤q，定义

    E_p(n) = ∫₀¹ |h(t)−n/q| dt
           = Σⱼ≥1 |dⱼ−n| p⁻ʲ。

它是波形与横线之间的非负面积。三角不等式给出 |x−n/q|≤E_p(n)。一般无条件用非负面积给出反向界需要证明，不能只假设不存在抵消。

令 c=n/q∈(0,1)，B=max(c,1−c)，λ(c)=(1−B)/(1+B)>0。事实上

    λ(c) E_p(n) ≤ |x−c| ≤ E_p(n)。

证明：若整串数位都等于 n，两边为零。否则令 k 为首个 d_k≠n 的位置，D=|d_k−n|≥1。此前壳层的高度差为0。第 k 层的带符号积分绝对值为 D p⁻ᵏ；之后所有壳的总宽度为 p⁻ᵏ，而逐点高度差至多 B。因此

    |x−c| ≥ (D−B)p⁻ᵏ,
    E_p(n) ≤ (D+B)p⁻ᵏ.

因为 (D−B)/(D+B)≥(1−B)/(1+B)，得到左侧不等式。对于 c=0 或1，高度差符号固定，因此恰有 E_p(n)=|x−c|。

## 3. 第一数位是最优横线

令 h 的第一层高度 c₀=d₁/q。第一层 I₁ 的长度为 q/p=1−1/p>1/2。对任意实数 c，第一层对 E(c)−E(c₀) 的贡献是 (1−1/p)|c−c₀|；其余层的差利用绝对值函数的三角不等式，至少是 −(1/p)|c−c₀|。于是

    E(c)−E(c₀) ≥ (1−2/p)|c−c₀|。

所以 p≥3 时，c₀ 不仅是最优的数位横线，而且是所有实数水平线中的唯一最优者。由此可以直接从第一位得到最小非负面积，不需搜索所有 n。记

    E_p = E_p(d₁) = Σⱼ≥2 |dⱼ−d₁| p⁻ʲ。

## 4. 与有理逼近的统一比较

让 D_q=min_{a∈ℤ}|x−a/q|。选最邻近 qx 的整数 n，令 c=n/q。固定 x∈(0,1)，令 δ=min(x,1−x)/2、λₓ=δ/(2−δ)。当整数 q≥max(2,1/x,1/(1−x)) 时，|c−x|≤1/(2q)，因而 δ≤c≤1−δ，且 λ(c)≥λₓ。

第一数位横线最小化 E，故 E_p≤E_p(n)。第2节给出 λₓE_p≤D_q；另一方面，D_q≤|x−d₁/q|≤E_p。综上

    λₓ E_p ≤ D_q ≤ E_p。

因此 liminf_{q→∞}q² E_{q+1}=0 当且仅当 liminf q²D_q=0；目标 x 是坏逼近数，也当且仅当 q²E_{q+1} 在充分大的整数 q 上有正下界。这是等价转换，不断言任一条件对 π 成立。注意 λₓ 依赖目标 x；不能把它误说成对所有目标一致的正数。

对 x=π−3，q≥8足够；之前针面积 A(q)=q²D_q/2，因此 q²E_p 两侧各乘1/2后也给出有限尺度的面积上下界。

## 5. 三个数位的非负证书

设 S_K=Σⱼ₌₂ᴷ |dⱼ−d₁| p⁻ʲ。由于所有 |dⱼ−d₁|≤q，

    S_K ≤ E_p ≤ S_K+p⁻ᴷ。

K=3时令

    H_q = q²[|d₂−d₁|/p² + |d₃−d₁|/p³]。

有 H_q≤q²E_p≤H_q+q²/p³，而 q²/p³→0。因而 P2848 等价于 liminf_{q→∞}H_q=0；等价地，存在 q→∞ 的子列使 d₂=d₁ 最终成立，同时 |d₃−d₁|/q→0。它是之前三位波判据的一种非负面积表达，仍不能由有限检查证明 π 的性质。
