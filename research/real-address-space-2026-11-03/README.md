# 用有限开区间给整条实数轴编址

2026-11-03。落实用户提出的“让 1/n 的 n 很大，以连续空间承载无限信息”的想法。这里给出一个保持有理结构的具体研究坐标；不把映射存在性当作新的逼近定理。

## 1. 连续地址函数

令地址 u∈(−1,1)，定义

\[
\boxed{\Phi(u)=\frac{u}{1-|u|}.}
\]

它是连续严格递增的双射，逆映射为

\[
\boxed{u=\frac{x}{1+|x|}.}
\]

u→−1、1 时，读数分别趋向−∞、+∞；区间中间的地址对应普通有限实数。必须用开区间：闭区间上的有限值连续函数有界。

这给所有实数提供一个有界地址空间。实数地址的无限数位可承载无限精确信息；指定某个实数仍需给定其信息，映射本身不生成未知内容。

## 2. 1/n 网格保留实际分子分母

第 n 层取地址 u=a/n，−n<a<n。直接得到

\[
\boxed{\Phi(a/n)=\frac{a}{n-|a|},\qquad
\gcd(a,n-|a|)=\gcd(a,n).}
\]

这一层有 2n−1 个地址，最远两点映射为 −(n−1)、n−1。所有有限层的并映射到全部有理数；无限精度地址及其极限覆盖全部实数。

设 p/q 既约、q>0，它的既约地址恰是

\[
\boxed{u=\frac{p}{q+|p|},\qquad n_{\min}=q+|p|.}
\]

因此 n 是一个明确的总高度层级。

| 网格地址 | 映射读数 | 最小层 n |
|---|---|---:|
| 22/29 | 22/7 | 29 |
| 355/468 | 355/113 | 468 |
| −22/29 | −22/7 | 29 |

正侧的变换 (p,q)↦(p,p+q) 是行列式为 1 的整数变换，可以接上仓库已有的幺模、有理网格与 gcd 工具。

## 3. π 的地址与已有进制函数

π 对应区间内的地址

\[
r=\frac{\pi}{1+\pi}\in(0,1).
\]

因此可直接研究已有面积函数 J_r(b)：仍在单位方块中逐层细分，最后通过 Φ 把有理地址读回整条实数轴。这里改变了目标面积参数；不把 J_r 与此前的 J_{π−3} 混称为同一曲线。

对既约正地址 u=a/n，令 p=a、q=n−a，则

\[
|\Phi(u)-\Phi(r)|=\frac{|u-r|}{(1-u)(1-r)},
\]

\[
\boxed{q^2|\Phi(u)-\pi|
=\frac{1-u}{1-r}\,n^2|u-r|.}
\]

故 u→r 时，两边的分母平方质量之比趋于 1。该坐标在局部保持原来的逼近尺度，没有通过坐标压缩省略整数分母成本。

若原网格 a/n 未约分，先取 g=gcd(a,n)，真实输出分母为 (n−a)/g，上式的地址分母也须改为 n/g。

映射的尺度变化也可明确读出：

\[
\Phi'(u)=\frac1{(1-|u|)^2}.
\]

靠近地址边缘时，地址误差被更强放大；例如 u=1−1/n 对应 n−1，局部放大率为 n²。把无界范围压入有限区间时，这项分辨率变化应保留。

## 4. 下一步的研究对象

这个模型将“无限内存”落实为无限层的有限网格：n 决定当前读取的精细程度，地址 u 决定对象，Φ 负责读回全实轴。n 可以增长，单个实数地址也可以继续读取更多数位。

固定任意 n≥2，也能在第 k 层使用 a/nᵏ 的地址；输出为 a/(nᵏ−|a|)。所以不必一次把 n 取到无限大，持续增加读取深度也能覆盖任意精度。第 k 层有 2nᵏ−1 个地址，选择一个地址所需的信息量约为 k log₂n 位；无限精度才对应无限容量。

具体接续是追踪 J_r(b) 的层波、原生地址的有理模板，以及 Φ 读回后的真实分母。此处只完成了坐标、网格和质量接口；没有构造新的 π 好逼近序列。

验证运行 `python verify.py`，仅用 Python 标准库。程序核对有限网格的完整覆盖与最小层、gcd，以及正负分支的精确质量转移。无限结论由上述公式证明。
