# 周期反馈实际带入 π：一次分母增长与质量改善

2026-11-02。接续 [成长函数工具](../growth-functions-2026-11-02/README.md)，直接检验反馈生成的周期分数能否改善 π 的实际逼近质量。

**本轮得到一次严格有效的有限步骤：22/7 → 355/113。分母7→113增长，同时 q²误差改善超过18倍。** 355/113是经典已知基准；本记录没有得到新纪录，也没有证明此步骤能无限重复。

## 1. 真正代入的模型与参数

在 [0,1] 定义

\[
\psi(u)=\begin{cases}
u,&0\le u\le1/4,\\
1/2-u,&1/4\le u\le3/4,\\
u-1,&3/4\le u\le1,
\end{cases}
\]

再作1周期延拓。选成长函数 f_κ(u)=u−κψ(u)，它满足 f_κ(n)=n，属于 G_1。演化是在它上面另加驱动

\[
F_{\Omega,\kappa}(u)=f_\kappa(u)+\Omega.
\]

这里 Ω=1 时才逐步沿原整数格点前进；本轮明确改变驱动，研究新的周期读数，未把原固定格点链的稳定性直接等同于周期比改变。

取粗驱动 Ω=1/7，完整输入分数为3+Ω=22/7。把反馈参数取成

\[
\boxed{\kappa=493/5000}
\]

后，精确认证出一个113步前进16个整数单位的周期轨道：

\[
F^{113}(x_*)=x_*+16.
\]

因 F 连续、严格递增并满足 F(u+1)=F(u)+1，这给出所有起点的平均步长

\[
\rho=16/113,\qquad 3+\rho=\boxed{355/113}.
\]

16与113互素，最小圆周期和实际既约分母都是113。周期点及其每步有理值均有精确证书；不是通过数值轨道“看起来重复”来判定。

## 2. 实际误差与实际分母一起改善

定义 Q(p/q)=q²|π−p/q|，其中 p/q 已完全约分。严格 Machin 有理区间给出：

| 项目 | 输入 | 反馈输出 |
|---|---:|---:|
| 既约分数 | 22/7 | 355/113 |
| 实际分母 | 7 | 113 |
| Q（小数仅用于显示） | 0.0619599741001313… | 0.00340631193013807… |

程序用有理上下界实际证明

\[
q_{\rm out}>q_{\rm in},\qquad
Q_{\rm out}<Q_{\rm in}/18.
\]

质量改善倍率的认证下界约18.18975342567。反馈造成的读数修正恰为

\[
\rho-\Omega=-1/791,
\qquad355/113=22/7-1/791.
\]

这个修正是周期认证之后计算出的输出差，不是预先把1/791灌进机器的输入。

相对于前一轮只让任意速度锁到1/2、1/3的工具基准，这次已经把读数、约分后的分母和π误差接在了同一项实际候选上。

## 3. 参数怎样选出，以及实验能证明到哪里

最初 κ≈0.0986 的线索来自面向 π−3 的探索性调参。因此不能称为完全盲发现，也不能把目标评分提供的信息删掉。随后固定并完整运行了网格

\[
\Omega=1/7,\qquad\kappa=j/5000,\quad1\le j\le600.
\]

每个参数先由有限浮点迭代提出周期和分支词，再用 Fraction 解出周期点并精确重放。π只用于正向周期认证后的质量评分；选择最优参数本身依赖这一评分。网格范围是在初步探索后确定的，并非独立预注册实验。

600个参数中有191个获得正向精确证书，409个未决。严格质量区间分离证明，355/113是这191个认证输出中最好的分数。未决不等于无周期，也不等于实际质量差，因此不宣称它是全部600个真实读数的最优，更不宣称所有参数或分数的全局最优。

完整参数、全部191份证书与未决索引见 [experiment/](experiment/NOTE.md)。

## 4. 整段参数的稳健性证明

本轮还认证了全部实参数组成的闭区间：

\[
\boxed{\Omega=1/7,\quad
|\kappa-493/5000|\le10^{-10}
\quad\Longrightarrow\quad\rho=16/113.}
\]

在中心参数，取周期点附近的严格区间 I，使113步之后减16的映射将 I 严格压进自身。它的内缩余量约8.0719362×10⁻⁵。整个参数区间内，113步映射的统一扰动上界约1.1893353×10⁻⁵，严格小于余量，所以整个实参数区间都保留周期读数。

所有有效性判断由 Fraction 完成，浮点只作上述数字显示。这个10⁻¹⁰是一个保守的可认证平台半径，不声称最大宽度；实际构造的中心参数仍是493/5000，没有为了中心点增加10位小数输入。完整证明见 [design/NOTE.md](design/NOTE.md)。

## 5. 从 q² 到单条 q 步证书

上一轮的精确算法构建 F^q 在整个单位区间上的全部分段，需要 O(q²) 次有理操作。本轮改为：

1. 浮点只提出 q 步分支词与整数前进量 p。
2. 固定词后，用有理运算合成 F^q(x)=Ax+B，并反推整个词的有效初值区间。
3. 解 x*=(p−B)/(A−1)，逐步精确检查周期点及其邻域确实留在相应分支。
4. 无浮点重放完整证书，验证闭合、约分和内缩。

A=1的情形单独处理。通过的证书是严格数学证据；没有通过只说明这次候选没有认证。每条词需要 O(q) 次有理操作，位复杂度并非 O(q)，中间分子、分母的增长仍保留。

同一 q113 输出被两种不同坐标的实现独立认证。q1009测试仅验证算法规模：输入已包含1009，且所用轨道不吸引，不作为新逼近或稳定构造。它的中间有理数达到30177 bit，保存指纹与费用，不把它混入搜索结果。

见 [algorithm/NOTE.md](algorithm/NOTE.md)。

## 6. 费用与下一条构造目标

周期点的有理高度约1385–1393 bit（不同坐标与相位选择略有不同）；参数493/5000的分母5000，也必须计入。用分子和分母的二进制长度直接相加，Ω与κ的两个有理参数共26 bit；这是明确的表示费用，不是最小信息复杂度定理。本轮只证明输出分数的质量改善，没有证明整个描述比直接写355/113更便宜。

若输入驱动 Ω=A/B，目标 α=π−3，定义输入误差 e=α−Ω、反馈修正 d=p/q−Ω，则

\[
\frac{Q_{\rm out}}{Q_{\rm in}}
=\left(\frac qB\right)^2\frac{|e-d|}{|e|}.
\]

因此下一步要设计可收费的参数选择律，反复同时满足

\[
q>B,\qquad |e-d|<(B/q)^2|e|.
\]

本轮已实证并认证了一次，但没有证明从输出再次启动时还能成功。仅仅让锁相周期越来越长，或按越来越多π数位调整反馈参数，均不足以单凭这套周期证书推出无限质量趋零。后续主攻是改变驱动/反馈的生成规律，而不是把旧族的排除问题恢复为主要任务。

## 7. 复现与独立审计

在本目录运行，全部只需Python标准库：

```sh
python3 experiment/run_experiment.py
python3 algorithm/verify_algorithm.py
python3 design/tongue_design.py
python3 design/verify_parameter_interval.py
python3 audit/verify_gain.py
python3 audit/verify_saved_grid.py
```

`audit/verify_gain.py` 使用独立的绝对坐标映射与更窄的Machin区间，核对113步周期、两端区间像、18倍收益及参数/轨道高度；它只从算法模块取得输入证书，不调用该模块的轨道更新或质量计算。

`audit/verify_saved_grid.py` 独立重放全部191份正向证书，共6666次绝对坐标映射运算，检查严格内缩、实际分母、质量区间包含关系、最佳输出及600项的认证/未决分区。它不重复浮点发现，也不把409项未决转成失败结论。

一般全指标与参数区间结论由正文证明，有限验证用于核对实现。基础理论承接上一轮标准圆映射与锁相机制，不主张基础原理首创性。
