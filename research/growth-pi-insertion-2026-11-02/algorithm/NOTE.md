# O(q) 行程证书：浮点只提案，全有理认证

本模块独立于 experiment 的实现。它使用与上一轮相同的连续单调分段线性 lift：F(u)=u+Ω−κψ(u)，0<κ<1，ψ 为1周期三角缺陷。没有读取 π 数字或目标有理分数来生成行程。对给定有理 Ω、κ，浮点轨道只提出候选；通过的证书都可以完全脱离浮点重放。

## 1. 为什么不必构造全部 q 步分段

旧算法构造 F^q 在整个 [0,1] 上的至多2q+1个仿射片段，需 O(q²) 次有理操作。若只需认证一个被提议的周期，可以固定一条长度q的行程，做一次线性遍历。

在模1相位中，每一步有三个可能输入区间：

- [0,1/4]：F(u)=(1−κ)u+Ω；
- [1/4,3/4]：F(u)=(1+κ)u+Ω−κ/2；
- [3/4,1]：F(u)=(1−κ)u+Ω+κ。

假设浮点轨道提出第i步使用的分支和整数跨格量 j_i。用精确有理数维护 u_i=A_i x+B_i。每次把输入分支条件、输出模1区间条件反推成初相位x的有理区间，再相交，得到全部指定行程的共同有效区间I。只要I空，立即拒绝此提案。

最后得到 u_q=A x+B，整数总前进量 p=Σj_i。若A≠1，周期点只能为 x*=−B/(A−1)。检查x*∈I后，再从x*精确重放全部q步，检查每个分支、跨格量与最终u_q=x*。通过即证明原lift满足F^q(x*)=x*+p，因此平均步长为p/q。输出会先约分。

若A=1、B=0，则I内都是该行程的周期点，取有理中点验证；若A=1、B≠0则拒绝。

**稳定性的额外条件**为A<1且lo<x*<hi。其中I=[lo,hi]。只有这一严格内部条件成立时，才把证书标为局部吸引；仅有周期读数不等于吸引周期。

## 2. 近返回提案怎样生成 p、q

`propose` 先做固定次数浮点预迭代，在得到的相位u_0之后，对q=1,…,max_period计算模1近返回距离。整数p来自这些q步实际跨格量的和，并处理模1端点接近的整数修正。取距离最小的若干候选，逐一调用精确认证器。

此处没有用有限平均速度的 `limit_denominator` 当作认证，也没有把目标π的连分数输入算法。浮点近返回不可靠时，精确部分只会拒绝，不能造成假阳性。

没有找到证书只意味着该启发式没有成功。它不证明不存在周期、没有锁相或旋转数无理。

## 3. 位数费用

设Ω=a/b、κ=c/d均既约、b,d>0。q步仿射斜率可写为 A=N_A/d^q，N_A=∏(d±c)。截距可放在共同分母2bd^q下，B=N_B/(2bd^q)。当A≠1时，周期点可表示为 x*=−N_B/[2b(N_A−d^q)]。

对周期行程作循环移位得到每个轨道相位的同型表达式。因此输出周期相位有充分位数预算O(log b+q log(2d))，分支有效区间和乘子也有同阶的线性位数规模。

认证只用O(q)次有理操作，**不等于O(q)位复杂度**。每次精确有理运算仍需大整数乘法、gcd与比较。输入中巨大的分母或长期行程成本没有消失。

## 4. 独立结果

`verify_algorithm.py` 保存三个小证书并完全有理重放：

| Ω | κ | 已约分周期读数 | 最大相位有理数位数 | 局部吸引 |
|---|---|---|---|---|
| 51/100 | 1/2 | 1/2 | 5 bit | 是 |
| 17/50 | 1/2 | 1/3 | 8 bit | 是 |
| 1/7 | 493/5000 | 16/113 | 1389 bit | 是 |

最后一行读回3+16/113=355/113。它是已知分数；本模块只独立认证其确实是反馈系统产生的周期读数，不把已有纪录重新称为新发现。

另做q=1009尺度基准：Ω=1/1009、κ=1/1009³，以指定近似初相位提案，严格认证周期读数1/1009。最大相位有理数为30177 bit。本提案得到的周期不是吸引周期；并且输入已经带有1009，所以它只验证算法能力，不是逼近发现。只保存完整中间证书的指纹与计数，不保留长轨道数。

本机上q1009例的构造与重放合计约8秒；时间仅为显示，不参与PASS判定，也不声称跨机器固定。

最后，Ω=177/1250、κ=1/10、max_period=1000的近返回提案未认证成功，按未解决案例记录。还检查篡改整数跨格量的证书会被精确重放器拒绝。

## 5. API 与复现

```python
from fractions import Fraction as Q
from itinerary_certificate import propose,certify_itinerary,verify_certificate
cert=propose(Q(1,7),Q(493,5000),max_period=1000,burn=20000)
assert verify_certificate(cert)
```

`certify_itinerary(omega,kappa,p,q,start)` 允许外部浮点检测器提出p、q与初相位。它仍独立执行精确的分支约束和轨道检查。

运行 `python3 verify_algorithm.py`。只需标准库。若要序列化几万bit的精确轨道，验证脚本显式提高Python十进制字符串位数上限；这只是序列化设置，不影响有理运算或判定。大数实例只保留计数、位数与哈希。
