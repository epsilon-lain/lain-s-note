## 1. 从“找到便宜列”改为“证明便宜列足够独立”

设矩阵有 M 行，把列成本归一化在 [0,1]。令 R(t) 等于成本不超过 t 的列的秩除以 M。则最便宜非零全行子式的平均成本严格等于
\[
C_* = \int_0^1(1-R(t))\,dt.
\]
实际算法是按成本从低到高扫描，每次只接受增加秩的列。附带全部成本前缀的秩，便可同时认证“非零”和“已经最便宜”；只展示一个非零行列式并不认证最优。

对原插值矩阵，重新选择权重后的秩下界给出
\[
\limsup_{H\to\infty}C_*(H)\le a\frac{m+1}{m+2},
\]
其中 m 是横向维数，a∈(0,1) 必须预先固定，并满足
\[
K(\theta/a)^m<1,\qquad K(w_0/v_0)(\theta/a)^m<1.
\]
这不是将权重改小后忽略算术成本：实际矩阵及列保持原样，新权重仅用于证明其中一个列子空间已经有足够的秩。原分母估计仍使用原权重。

一个可精确比较的参数例子是
\[
m=2,\quad K=2,\quad\theta=1/2,\quad w_0/v_0=5/16,
\quad\rho=5/32,\quad a=3/4.
\]
旧最坏选列上界为 U₂(5/32)=67/80；新上界为 9/16。前者的成本分位点为 3/4，因为 F₂(t)=3t²−2t³ 且 F₂(3/4)=27/32。尾部第一矩除以 5/32 恰得 67/80。

所以此例中保证的列成本上界减少了 **11/40**。这些是行列式比较中的无量纲成本上界，**不是 π 的逼近误差，也不是已有固定权重自动获得的收益**。水平权重还须按定理依次选大；所有参数与中心先固定，再取 H→∞。本例没有完成其余解析成本的比较。

## 2. 一个实际可写出的非零子式

在 Kθ<1、v₀>w₀ 的较强参数范围内，现已将仓库的一维 Hermite 构造扩展到多维。对每个时间阶 s 与其余坐标指标 γ，记允许的第一坐标导数数目为 Jₛ,γ。取列
\[
Y^sX_1^b(X')^\gamma,\qquad0\le b<KJ_{s,\gamma}.
\]
它们构成全部行的方形非零子式，精确行列式是 Hermite 因子的乘积。平均列成本趋于
\[
\frac{(K+m-1)\theta}{m+2}.
\]
但这个具体子式在所有中心趋于精确周期 2πi 时仍然非零，且 |r₁|>1、K≥2 时模大于 1。因此不能把它的低成本和另一个子式的周期相消收益拼成同一个反证。

## 3. 为什么还需要识别真正非零的展开项

旧松弛允许每行都选 a=β、d=0。这使全部误差改善因子消失；即使将列成本做到最优，它也给出必要门槛
\[
\frac{v_0}{w_0}<\frac{\log2}{200(m+2)}.
\]
因此 v₀>w₀ 的区域过不了这套松弛评分。**这是松弛的障碍，不是 π 的性质，也不是完整行列式方法的障碍。** 因为那个压低评分的“不移动项”，其行列式本身可能恒为零，本来就不必参与解析上界的最坏比较。

本轮给出一种精确识别办法。令 Z 为形式变量；对选列 P=YʰX^α，纯周期平移行 e=(j,ℓ,a) 写为
\[
V_{e,P}(Z)=\binom\alpha a[t^\ell](1+t)^h
\bigl(jZ+\log(1+t)\bigr)^{|\alpha|-|a|},
\]
当 a 不逐坐标小于等于 α 时取零。|α| 是各坐标之和，多重二项式系数是各坐标二项式系数的乘积。有限取系数使每个元素属于 Q[Z]。

代入 Z=2πi 恰好得到精确周期行，因为 h、j 是整数，e^(2πihj)=1。又因 2πi 超越，非零有理系数多项式不可能在此变为零，所以
\[
\operatorname{rank}_{\mathbb Q(Z)}V(Z)
=\operatorname{rank}_{\mathbb C}V(2\pi i).
\]
这使“哪些候选展开项的行列式为零”成为有限精确代数计算，无需以小数猜测。

在仓库已有的四列例子 1、X₂、X₂²、X₁ 上，工具得到：

- 不移动的四行矩阵秩为 **3**，行列式严格为零。
- 16 个候选行选择中，12 个向量行列式为零，4 个非零。
- 最小存活总位移次数从松弛中的 0 提升到 **1**。
- 把全部非零项及其标量相加，精确恢复 **2r₂(r₂−r₁)**。

这个 4×4 例子本身来自旧记录，本轮新增的是对其展开项的符号秩认证与可复用取系数工具。次数 1 在固定实例中成立；尚未证明随 H 增长的完整行数矩阵有足够大的最低非零位移成本。不同非零展开项仍可能相互抵消，不能以存在一个非零项推出总行列式非零。

另外，在同一行包、中心 r₁=2、r₂=3、全部总次数不超过 2 的十个原单项式列中，精确贪心工具选出的最小横向总成本为 2；该选列的纯周期矩阵秩仍为 4。上面的相消见证总成本为 4。这是在实际有限矩阵上对两种目标的直接比较：便宜选择并不自动保留相消；这里也没有断言最小成本基一定唯一。

## 4. 可复现工具与核验范围

```bash
cd research/contradiction-rank-2026-11-01
python3 verify_rank.py > results_rank.json
python3 verify_hermite.py > results_hermite.json
python3 period_rank.py > results_period.json
```

前两个脚本仅需 Python 标准库；最后一个依赖 SymPy，本次使用 1.14.0。

- [rank_minor.py](rank_minor.py)：有理矩阵的最小成本非零子式与前缀秩证书。[独立核验](verify_rank.py)遍历全部小型子式，与 180 个输入矩阵的算法结果比较，其中 171 个满秩、9 个秩不足。
- [verify_hermite.py](verify_hermite.py)：直接构造实际 Taylor 系数矩阵，验证六个二维、三维子式，包括 26×26 矩阵、不同权重和完全相同中心。
- [period_rank.py](period_rank.py)：纯周期行的多项式构造；48 次独立求导取系数核对；完整枚举四列例子的展开并重建原行列式。

有限核验不验证外部插值定理的全部阈值，不代替文中的一般证明；没有运行 Lean。

## 下一断点

现在需要对**同一个**非零子式，同时控制列成本和最低存活展开代价。候选展开向量按原始行分组，每组必须选一项，并且全部选中向量必须线性无关；这比普通逐列贪心多了分组限制。符号秩判据已经提供精确的独立性检测，但尚缺随 H 增长的统一下界及最终算术—解析比较。
