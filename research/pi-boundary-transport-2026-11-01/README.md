# 主线推进：精确消去内部偏移，保留边界混合子式

2026-11-01。接续[真实周期结构](../pi-period-structure-2026-11-01/README.md)和[近期文献接口](../pi-recent-literature-2026-11-01/README.md)。

**本次得到的是新的精确改写与可检验的证明目标；没有证明 π 是坏逼近数。** 代数恒等式独立成立；关键高维参数下非零原始子式的存在，仍以原稿插值定理为条件。

## 1. 改写了主线的待估计对象

原来考虑把有理中心直接移到真实周期，再控制整个扰动。现在先把位置偏移转成导数方向的变化。在完整加权导数包内，所有内部变化都能通过行列式为一的行变换精确消去，只有越出导数预算边界的项留下。

令 ω=2πi，r_i=2ip_i/q_i，b_i=r_i/ω，ζ_i=(r_i−ω)/r_i。对同一个原始单项式方阵，有精确式：

\[
\det A(r)=b^{\sum\alpha-\sum\beta}
\det\bigl(B^0_L+R(\zeta)B^0_O\bigr).
\]

B^0 全部使用原来的真实周期列函数。L 是原有导数包，O 是包外行。条件是每个横向导数成本 w_i/θ 至少为时间成本 v_0；原始列缩放式不直接适用于任意混合列。

- [完整证明与边界交错和](transport/SHEAR_BOUNDARY_IDENTITY.md)
- [系数预算、混合子式展开及精确算术比较](budget/BOUNDARY_BUDGET.md)

对位于预算内部深度 g 的一行，残留项必须积累足够多的 ζ 因子才能越界。已证明每个有效边界系数的界为

\[
|R_{\rho,\gamma}|\le3^{H/w_*}e^{-\tau g_\rho},
\qquad
\tau=\min_i\frac{-\log|\zeta_i|}{w_i/\theta-v_0},
\]

这里取严格正成本差与 0<|ζ_i|<1；零成本方向另有精确消去。这个界只控制系数，外部导数行的大小和混合行列式仍需付费。

## 2. 为什么暂时停止直接搬用零偏移 Gram 估计

[精确核反例](obstruction/GRAM_DISPLACEMENT_OBSTRUCTION.md)证明：两个中心各取 n 个连续导数，即使固定偏移 δ 极小，通用 Gram 比值仍可满足

\[
\frac{\det G_n(\delta)}{\det G_n(0)}
\ge |\delta|^{2n}
\left(\frac{R^2-|\omega|^2}{|\omega|^2}\right)^{n^2}.
\]

因此“位置很近”不足以让周期处的二次指数节省稳定保留。另一个基于算术下界的结论把这一障碍带到了原有完整高维包，但保留原稿秩假设。

同时，[真实列的兼容性例子](budget/COMPATIBLE_COLUMNS.md)给出同样两个横向类型、列 Y^h 与 XY^h 的精确行列式 det A_n(r)=r^n。它的相对对数变化只有 n 的量级。通用核空间把各类型函数视为可以独立变化，而实际列之间有 f_0=z f_1 等关系。这些关系必须在后续估计中保留。

## 3. 下一步要证明的具体不等式

按边界替换的行集合展开新行列式，估计每个混合子式的增长，减去那些被替换行真正获得的误差幂收益，再与同一原始子式的精确分母成本比较。[预算文档式 (10)](budget/BOUNDARY_BUDGET.md)写出了充分的严格不等式。

目前没有证出该不等式。仅把所有行的深度平均起来，端点尺度下只得到约 2θ/(m+2) 的系数收益，而且这还只属于全部换成边界项的那一项；不能把它分配给所有混合项。接下来需要保留实际列关系，控制这些混合项的总体贡献。
