# 确定性的数位波离线条件

2026-10-27。用户提出“不总围绕一条横线，必定偏离”，这里选取一种可检验、与坏逼近等价的定量版本。它研究每个进制的前几位，不假定这就是用户原意的唯一形式；下面是初等推导，不声称文献首创。未运行 Lean，未证明 π 的逼近性质。

## 1. 模型

固定无理数 x∈(0,1)，正整数 q≥2，令 p=q+1。将 x 以整数进制 p 展开，前3位分别为 d₁,d₂,d₃。令

    D(q)=min_{a∈ℤ}|x−a/q|,
    E(q)=Σ_{j≥2}|d_j−d₁|/p^j。

前文 DIGIT_RECTANGLE_INTEGRAL_2026-10-27.md 已证明：存在只依赖 x 的常数 λ_x>0，使所有充分大的 q 满足

    λ_x E(q) ≤ D(q) ≤ E(q)。                              (1)

并且尾项不超过 p^(−3)：

    0 ≤ E(q)−(|d₂−d₁|/p²+|d₃−d₁|/p³) ≤ p^(−3)。       (2)

## 2. 一个完全确定性的条件

对于固定无理 x，下列条件等价：

(A) x 是坏逼近数。

(B) 存在 η>0 和整数 Q，使每个 q≥Q 满足至少一条：

    d₂ ≠ d₁，或者 |d₃−d₁| ≥ ηq。                       (3)

这里第一条只要求第二位与第一位不相同；如果第二位仍在横线上，第二条要求第三位与横线的距离至少是进制尺度的固定比例。它不是统计频率、随机性或概率假设。

(B) 推出 (A)：如果 d₂≠d₁，由数字是整数可知 E(q)≥p^(−2)；否则 E(q)≥ηq/p³。当 q≥2，

    q²E(q) ≥ min(4/9, 8η/27)>0。

结合 (1) 给出 D(q)≥C/q²。x 无理，所以有限多个小 q 的距离均大于0，将它们并入常数，得到对所有 q 的坏逼近下界。

(A) 推出 (B)：设 D(q)≥C/q²。如果 d₂=d₁，由 (1) 右侧和 (2) 得

    C/q² ≤ E(q) ≤ (|d₃−d₁|+1)/p³，

即 |d₃−d₁|≥Cp³/q²−1>Cq−1。对于 q≥2/C，该值≥Cq/2；因此可取 η=C/2。

这个等价给出如何严格表达一种“迟早要明显离线”：对每个大的进制，若第二位未离线，则第三位必须离开至少ηq；更弱的“某一天离开”不足以给出同样的定量结论。它仅重述性质；对 π 仍须找到不以 π 坏逼近为假设的独立证明。

## 3. 例子：根号二

设 x=√2−1。对任何 q≥1 和 n∈ℤ，有

    |x−n/q| > 1/(4q²)。

证明：当 n/q∈[0,1]，n+q 的平方与2q²为不同整数，故

    |x−n/q| = |2q²−(n+q)²| /
                 [q²(√2+1+n/q)] > 1/(4q²)。

当 n/q 不在[0,1]时，距离大于1/4，也满足此式。于是 D(q)>1/(4q²)。

对任意 q≥8，如前两位 d₂=d₁，则由 (2)：

    1/(4q²)<D(q)≤E(q)≤(|d₃−d₁|+1)/p³，

所以 |d₃−d₁|>p³/(4q²)−1>q/4−1≥q/8。于是

    d₂=d₁  ⇒  |d₃−d₁|≥q/8,   q≥8。                    (4)

例如 q=70、p=71，√2−1 的前三位为 [29][29][3]，第三位离开29的距离为26，大于70/8。证明来自平方根的整数方程，不依赖统计。

Python 整数平方根产生的80位有理区间，对 q=8,…,10000 检验了全部首三位；其中8个进制的前两位相等，均满足 (4)。有限检查不是 (4) 的证明。

## 4. 与刘维尔数和 π 对照

此前 LIOUVILLE_WAVE_BELOW_Q2_2026-10-27.md 证明：标准刘维尔数在 p_k=10^(k!)+1 进制的前 k 位均相同。因此 k≥3 时 d₁=d₂=d₃，对任意 η>0，条件(3)在无穷多个尺度失败。这不是通过统计否决，而是构造明确失败位置。

对于 x=π−3，q=113、p=114 的前三位是 [16][16][15]。在这个尺度第二位相等、第三位距离是1；如果某个 (3) 所用 Q≤113，则η不超过1/113。条件只要求所有充分大的 q，单个有限数值不证明或反驳 π 坏逼近。
