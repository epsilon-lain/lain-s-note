## “正文首读完成”的含义

阅读对象是当前 PDF 对应的主 TeX，以及递归输入的全部数学正文和附录。局部声明、证明中间步骤、后续推论都在阅读范围；不是只取标题、摘要或结论。相关宏、图的说明/可读源码和参考文献也列在实际阅读记录中。独立的示意图 PDF 资产不等于数学正文，其处理范围在各篇 scope_note 中注明。

每份记录保存：

1. 固定提交、稿件路径、主源码与源文件 blob SHA。
2. 源文件行数和实际读过的连续区间；未读区间必须保留。
3. 原稿声称的结果、证明架构、构造机制及其使用前提。
4. 跨领域的候选迁移思路、缺少的桥梁和独立核验的范围。

`full_body_read` 只在完整源码阅读闭包满足条件时使用。下载到本地不产生阅读完成记录；行数合并不重复计数。部分论文由多个阅读分支接续，原始分支记录保持当时状态，最终 ledger 合并明确读过的区间。第 6、18 项的续读证据分别见 `continuation_07/08` 和 `continuation_09`。

**正文首读完成不是独立证明验证。** 例如某篇把关键定理作为外部文献或 companion paper 输入，读完本篇并不等于那个外部证明也已读完。后者作为依赖保留；若它在本库有独立稿件，它仍会按自己的队列位置阅读。没有运行这些论文的 Lean，没有宣布目录内所有主张正确。

## 构造思路怎样保留

每篇至少保留具体构造机制和前提，而不以“当前没有直接接口”作为跳过理由。初步思路见 [IDEAS.md](IDEAS.md) 及六个批次的笔记：

- [batch_01](batch_01/notes.zh.md)：有界次数多项式的避零、保留严格余量的有限测试、共同列和约束下的局部交换。
- [batch_02](batch_02/notes.md)：共同证人、可行基质量、清洁坐标与对坏纤维的擦除、极限环论证的有限复杂度势。
- [batch_03](batch_03/notes.md)：非均匀联合分布与均匀边缘、循环测试、正整数直方图和有限约束的一致性。
- [batch_04](batch_04/notes.md)：行/列双重有限分配、共同线性/二次预算、余核矩的精确消去与正性。
- [batch_05](batch_05/notes.md)：可预测的秩积累、固定格点与任意多次等分、极大缺陷取得和缺陷放大。
- [batch_06](batch_06/notes.md)：固定指数的几何修正、带符号的共同占用预算、整性和除法归一化的区别。

这些是有来源条件的候选，不是已迁移到 π 的定理。例如 Tingley 稿件里的极限空间可以帮助取得极大缺陷，但没有自动保存本项目所需的标准有限整数、分母高度或 π 特有运算。有限域、算子、概率和几何机制都需要在后续构造中重新建立接口。

在完整首轮阅读结束前，这些思路按篇登记；不会因为暂时看不出用途而改变全库覆盖范围。当前也没有据此证明 π 坏逼近或非坏逼近。

## 阅读台账工具

```bash
python3 research/openai-math-corpus-2026-11-01/full-reading/reading.py build
python3 research/openai-math-corpus-2026-11-01/full-reading/reading.py pending --limit 20
python3 research/openai-math-corpus-2026-11-01/full-reading/verify_reading.py
```

第一条从原始分支记录和续读记录生成台账，不会自行把缓存文件标为已读。`pending` 保留部分正文与未开始项，供续读。测试检查队列不遗漏、不重复，以及缺失区间、附录或闭包说明时拒绝“已读完”标签；它不能机械证明理解或正确性。

初始化完整上游子模块以后，可以核对全部记录中涉及的真实源文件：

```bash
python3 research/openai-math-corpus-2026-11-01/full-reading/audit_sources.py --checkout external/openai-math
```

本轮的缓存字节核对结果保存在 [source_audit.json](source_audit.json)。这将源文件身份与阅读区间对上，不将“字节核对通过”混同“数学定理已核验”。
