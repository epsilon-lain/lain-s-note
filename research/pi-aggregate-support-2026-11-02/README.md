# 完整求和、逐层时间容量与平均次数集中

2026-11-02。接续[同列预算与近全逃逸](../pi-near-total-2026-11-02/README.md)。本轮沿着“还有剩余时间预算”继续：把完整输运和写成同列多项式，得到逐时间截面的约束，并证明平均目标次数的第二重集中。另明确哪些对称模型根本无法提供非零源子式。

**本轮仍未证明或否证 π 的坏逼近性，没有新的 π 逼近纪录，没有独立认证所给原稿的 Theorem 2.1。** 下述证明分别有明确的列基、参数及极限顺序；有限非零不代替大小估计，单项非零也不代替完整求和。

## 1. 从单项推进到完整求和

固定同一批列，让中心参数为 \(Z\) 时的完整源行列式为 \(P_C(Z)\)，空间次数差为 \(D\)。在一维中，全部输运贡献的精确总和是

\[
\boxed{\mathcal F_C(\zeta)
=(1-\zeta)^D P_C\!\left(\frac{\omega}{1-\zeta}\right),
\qquad\omega=2\pi i.}
\]

这保留了所有符号相消。多维版本由 \(P_C\) 的倒数多项式给出，并有按齐次部分逐一检查系数是否为零的代数判据。

两个完整实例把现象区分开：

- 六行模型的 36 个目标选择中，有 11 个周期子式非零；六个非零二阶项严格抵消，完整总和只剩常数和一次项。
- 先前的 32 行真实列证书中，完整误差多项式次数为 35，完整三十阶系数在实际周期处严格非零。这里没有声称某个单项独自留下，也没有把误差次数当作移出行数。

还得到一条精确限制：在一维，或多维共同径向偏移方向上，若完整误差多项式非常数，则从零次到最高次的每个系数都非零。这个结论利用 \(2\pi i\) 的超越性，只判断是否严格为零，不判断是否很小；它不适用于一般独立误差方向。

另构造了所有充分大高度适用的列替换族，总和可精确写成常数乘 \((1-\zeta)^r\)。它的正时间余量可以计算，但 \(r=O(H)\)，在 \(MH\) 尺度上的额外效应趋于零。因此“总和非常数”本身仍不足以完成端点比较。

详见 [RECIPROCAL_RESUMMATION.md](RECIPROCAL_RESUMMATION.md)、[AGGREGATE_PERIOD_POLYNOMIAL.md](AGGREGATE_PERIOD_POLYNOMIAL.md)。

## 2. 总预算必须升级成每一层的容量

令 \(S_r\) 是时间阶数至少为 \(r\) 的源行数，\(d_r\) 是所选列空间中含因子 \((Y-1)^r\) 的子空间维数。第 \(r\) 层可供移位消耗的容量是

\[
C_r=S_r-d_r.
\]

任何同时具有非零输运系数和非零周期子式的目标，都必须在**每一层**满足“跨过这一层的行数不超过 \(C_r\)”。把这些条件相加才得到上一轮的总余量条件；总量够用仍可能在某层卡住。

对任意选定的原始单项式列，若与空间类型 \(\alpha\) 配对的不同 \(Y\) 指数共有 \(k_\alpha\) 个，则

\[
d_r=\sum_\alpha\max(k_\alpha-r,0).
\]

这只使用原列空间，不需要假装任意原始列集合都能原样换成移位列。由此还得到跨层反馈秩和外部行数标记的次数上界。

一个六行实例中，5 个目标通过总余量检查，只有 3 个通过逐层检查，并且恰好只有这 3 个周期子式非零。另一个八行例子达到新的标记次数上界 6，而总位移次数为 12。

不过在关键高维族中，这个标记次数上界本身仍可接近总行数，因此逐层条件尚不能单独排除近全逃逸。

详见 [FILTERED_TIME_SUPPORT.md](FILTERED_TIME_SUPPORT.md)。

## 3. 剩余贡献还必须具有足够大的平均目标次数

给目标空间类型 \(a\) 的行数记为 \(n_a\)，它的归一化加权次数为 \(x_a=w\cdot a/H\)。固定总行数及平均次数上界，精确最小化碰撞量 \(\sum_a n_a^2\)，得到分段最优公式；低平均次数分支的最优密度与 \((A-x)_+\) 成正比。

对原来的关键参数 \(B=3/5,\theta=1/2,C=13/10\)，这给出新的条件性集中：在源子式非零、算术下界及足够大的权重和高度条件下，低于下列平均次数的目标总和不足以承载算术下界。

| 维数 \(m\) | 必须保留的区域：平均 \(w\cdot a/H\) 大于 |
|---:|---:|
| 40 | 0.497 |
| 80 | 0.541 |
| 120 | 0.558 |
| 200 | 0.573 |

它可以与上一轮“几乎全部移出”的条件取交集。这里的次数是辅助矩阵的导数次数，不是 π 有理逼近误差的概率分布。

同时也证明了该松弛的限制：保留实际不同列、坐标次数差和最优平均碰撞后，对固定 \(\theta<1\)，当前 Cauchy 估计及 LCM 算术归一化的最优剩余成本缺口仍为

\[
(1-\sqrt\theta)^2>0.
\]

在 \(\theta=1/2\) 时，它约为 \(0.0858\)。这是估计中归一化指数的缺口，不是 π 与有理数的距离。证明包含可行的松弛数据，因而不只是没有找到更强不等式；这些数据仍未满足完整时间匹配和行列式非零条件。改变归一化、利用相消，或令 \(\theta\) 随维数趋于 1，都不被这条固定参数结论排除。

详见 [MEAN_DEGREE_AND_COLLISIONS.md](MEAN_DEGREE_AND_COLLISIONS.md)。

## 4. 对称高维模型的非零性不能默认成立

相等空间权重允许把完整行列空间按法向次数精确分块。共同周期点的活动方向是一维；一般偏移中心连同时间方向至多张成二维。

把所有法向块的容量相加后，得到：在相等空间权重的关键半密度族中，源矩阵可具有的秩占比随维数指数下降，**即使离开共同周期对角线也如此**。例如 \(m=10,\theta=1/2\) 时，先取高度极限，偏移源矩阵的秩占比上界只有 \(29/128\)。因此不能把这个对称模型当成已有非零算术源子式的模型。

对不同权重，则得到活动平面的必要分离条件。在中心坐标两两不同、权重递增时，关键族的满行秩要求

\[
\frac{w_{m-1}w_m}{w_1w_2}\ge\frac1{2\theta^{m-2}}.
\]

这是必要条件，不能倒过来当成满秩保证。强烈分离的权重可以满足它，所以没有据此反驳原稿插值定理。

详见 [ACTIVE_SPAN_AND_PROFILE_CAPACITY.md](ACTIVE_SPAN_AND_PROFILE_CAPACITY.md) 及 [EXACT_BIVARIATE_BLOCKS.md](EXACT_BIVARIATE_BLOCKS.md)。
