# 有符号余项构造：整数矩滤波与共享分母

2026-11-10。接续 [联合选择权重](../pi-joint-selection-2026-11-10/README.md)，源版本为 `c6b02f113e8527b57622d7fb8f6f60eaece91d81`。

**本轮实际构造并测试了保留误差符号的滤波器。部分同阶对照中，误差与真实分母成本同时改善；最终仍没有超过 355/113，没有新纪录或无限成功族。**

目标仍是生成既约 p/q，使 `Q=q²|π−p/q|` 沿无界分母子序列趋零。辅助 π² 源的质量 `B²|π²−A/B|` 与最终 Q 是不同的量，下面分别报告。

## 1. 同一积分内安排相消，同时控制共享分母

第一组使用经典 Euler／二项滤波。对 `c=s/t>0`，用前 n 项 Taylor 多项式 T_n，选择非负权重

\[
w_j=\binom{k}{j}\frac{s^{2(k-j)}t^{2j}}{(s^2+t^2)^k},
\qquad F_{n,k}(c)=\sum_{j=0}^k w_jT_{n+j}(c).
\]

相邻截断的误差异号，合并后有精确余项

\[
\arctan c-F_{n,k}(c)=(-1)^nc^{2n+1}
\left(\frac{c^2}{1+c^2}\right)^k
\int_0^1\frac{x^{2n}(1-x^2)^k}{1+c^2x^2}\,dx.
\]

这里相消来自同一个积分中的 `(1−x²)^k`。更重要的是，权重的 `t^{2j}` 会同时抵消后续截断项的分母幂。令 `N=n+k`、`L_N=lcm(1,3,…,2N−1)`，则

\[
\boxed{\operatorname{den}F_{n,k}(s/t)
\mid t^{2n-1}(s^2+t^2)^kL_N.}
\]

这是一条先于实验成立的分母账式。最终合并角读数时使用这些共享分母的最小公倍数，计算完整整数分子和实际 gcd，随后评价既约分母 q。

对 Gregory、两角 `1/2,1/3`、Machin 三个家族，测试 `1≤N≤40` 的 2,460 个候选。每个 N 都与同一最高 Taylor 阶数、k=0 的普通截断比较：三组在所有 `N=2,…,40` 上都有真实 Q 改善，共 117 个匹配阶数改善。

| 三个家族各自的全范围最好候选 | 实际 Q 约值 |
|---|---:|
| Gregory：4/1 | 0.8584 |
| 两角：10/3 | 1.7257 |
| Machin：3804/1195 | 59507.15 |

例如两角家族 N=40 时，选择 n=13、k=27，既约分母由普通截断的 302 位降至 190 位（二进制）。其 Q 比基线小约 80 个十进数量级，**绝对 Q 仍约为 `1.59×10^76`**。所以这里确实同时改善了相消和算术成本，但基线很差，不能据此认为已经接近爆破解，也没有证明优于其他已知有理逼近方法。

完整公式、Beta 误差界和费用证明见 [THEORY_EULER.md](THEORY_EULER.md)。基础变换是经典工具；本轮不声明其原创。

## 2. π² 的整数矩滤波：保留真实误差依赖

第二组从 Beukers–Apéry 的精确矩余项出发：

\[
u_n\zeta(2)-v_n=(-1)^n\int_0^1\int_0^1
\frac{\tau(x,y)^n}{1-xy}\,dx\,dy,
\qquad \tau=\frac{x(1-x)y(1-y)}{1-xy}.
\]

其支撑满足 `0≤τ≤(5√5−11)/2`。取整数多项式 `H_k(τ)=(1−11τ−τ²)^k`，以相应整数系数组合相邻源，得到新的 U、V 及既约源 `A/B=6V/U`。滤波余项恰为原积分内乘上 H_k，符号和严格有理上界均可由它认证。

本轮同时计算 U 的变化、V 的完整清分母费和真实 gcd。对 `n≥1,k≥0,n+2k≤128` 的 4,160 个源，其中 4,032 个为非平凡滤波源；有 1,064 个的实际辅助质量 `B²|π²−A/B|` 优于**同一最高输入源指标 n+2k** 的未滤波源。

一个完整收费的例子：最高指标同为 128，普通源的既约 B 为 789 位，滤波 n=120、k=4 后为 739 位（二进制）；辅助质量从约 `2.5234×10^208` 降至 `1.3207×10^187`。二者仍极差，而且全范围最好的滤波源也没有超过全范围最好的未滤波源。

对这些源再运行两个原小范数预算，检查 229,118 个根式收敛分数。6 条合格预算记录仍只给出 `3、22/7、355/113`，最终最好 Q 仍约为 `0.00340631193013807`。这里源误差使用新积分证书，包括 k=0 在内；它与旧相邻源的区间宽度不同，因此这不是与旧生成器的同证书对照。

需要特别保留一条等价性检查：k=1 的整数滤波精确化为

\[
u_n+11u_{n+1}-u_{n+2}
=\frac{(2n+3)u_n+(11n+19)u_{n+1}}{(n+2)^2},
\]

v 也同样成立。因此这一源仍属于旧相邻源的正权重空间。新增的可用信息是实际有符号积分余项，而不是凭整数系数正负就宣称产生了新方向。证明及预算搜索完整性见 [MOMENT_THEORY.md](MOMENT_THEORY.md)。

## 3. Aitken 作为费用对照

另测试了 9 个源指标的三点 Aitken 变换。它消去局部几何余项，9 组的绝对源误差都优于 r_n；但相对 r_n 的 `B²×误差` 都恶化。考虑到变换读取 n、n+1、n+2 三项，本轮也与同一最高输入指标 r_{n+2} 比较：只有 n=1 的低阶样例改善，其余 8 组恶化。

这组数据用来选择后续投入方向；不是某个无限构造的失败定理。精确比值、变换后的整数分数和逐项摘要见 `aitken_results.json`。

## 4. 独立验证与复现

三组数据均有另一种公式或实现重建。独立验证不是外部同行评审，本轮也没有 Lean 形式化。

- Euler 组：用多项式长除法和商的积分重建 4,100 个角读数及 2,460 个最终分数；独立计算 Beta 矩、实际分母/gcd、完整摘要和全部同阶比较。
- 整数矩组：用二项式和及 Casoratian 累加重建源，用多项式系数的多项式组合公式复核滤波，用二进根式区间抽取连分数，检查全部 4,160 个收费记录和最终命中。
- Aitken 组：用独立源公式及行列式表达式重建三点变换，核对同起始指标、同最高输入指标两种成本比较。

三组实际误差都通过严格有理 Machin–Taylor 包围区间评分。生成系数和分数时不输入 π 小数或 π 连分数表；π 区间只用于事后核验与有限候选比较。

从本目录运行，只依赖 Python 3 标准库以及仓库已有脚本：

```sh
python3 fresh_probe.py
python3 fresh_verify.py
python3 moment_filter.py
python3 moment_filter_verify.py
python3 aitken_probe.py
python3 aitken_verify.py
```

紧凑数据保存每条精确记录的参数和 SHA-256，关键样例另存完整整数。独立验证器重建省略的精确记录后核对摘要。`manifest.json` 给出本轮文件和旧依赖的指纹。

## 5. 本轮留下的构造问题

现在有了两种实际生成器，能把“误差如何相消”和“分母哪些部分会被抵消”同时写入构造。有限实验也确认了部分真实算术收益。**仍缺的是把这种收益提高到最终 Q 趋零的量级，并证明它反复发生。**

后续若改造这类滤波，应以更强的原始有理逼近为输入，并在设计余项多项式时同步处理周期系数和实际分母。仅增加滤波次数，或只比较一条很差的 Taylor 基线，不能保证推进这个目标。上述限制用于指导下一次构造，不替代构造本身。
