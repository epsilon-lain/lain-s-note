# 单位分数路线：有限搜索与一个可核验的障碍

日期：2026-11-03。目标始终为实际既约质量
\(C=q^2|\pi-p/q|\)，越小越好。
本轮得到一个带完整证明的**单步有限优化工具**，没有构造出新的 π 逼近纪录。

## 直接结果

固定既约起点 \(p/q\)。从下方出发允许加上一个正单位分数，从上方出发允许减去
一个正单位分数；两种情况下均要求结果仍留在 π 的原侧。
所有无限多个候选 \(1/d\) 的最佳实际质量，必在至多
\(\tau(q^2)\) 个可显式构造的候选中取得。
这里 \(\tau(q^2)\) 是 \(q^2\) 的正约数个数。

机制是：约分后的新分数 \(P/Q\) 满足
\(D=|Pq-pQ|\mid q^2\)。对每个 \(D\)，新分母 \(Q\) 落在一个同余类中，
只需取超过严格误差边界的第一个格点，然后约分并评分。
完整推导在 [THEORY.md](THEORY.md)；没有对这个有限化简提出文献首创性主张。

| 起点 | 保持侧别 | 候选数上限 | 最佳单步结果 | 原 C | 新 C |
|---|---|---:|---|---:|---:|
| 22/7 | π 上方 | 3 | 355/113 | 0.0619600 | 0.00340631 |
| 333/106 | π 下方 | 9 | 688/219 | 0.935056 | 1.92526 |
| 355/113 | π 上方 | 3 | 104348/33215 | 0.00340631 | 0.365864 |

第一行精确等式为

\[
\frac{22}{7}-\frac1{791}=\frac{355}{113}.
\]

第三行则说明：**从355/113出发，保持上侧的单次单位分数修正，全部都不能改善原质量。**
这只排除指定的一步模型；它不排除多项联动、允许越过 π 的修正或其他构造。
上方起点使用减法，是对称对照，不是把原来的正单位分数求和模型静默改成有符号模型。

## 原来的贪心展开为什么暂时不适合直接破纪录

对 \(\pi-3\) 每次减去最大的不超过余项的单位分数，确实快速收敛。
但精确约分后的数据为：

| 本次加入的单位分母 | 部分和实际分母 | C |
|---:|---:|---:|
| 8 | 8 | 1.06193 |
| 61 | 488 | 47.4409 |
| 5020 | 612440 | 2917.99 |
| 128541455 | 3148957148008 | 6.08622×10⁷ |

加到第8个非整数单位分数时，实际分母已有270位，质量约为
\(3.9150\times10^{262}\)。这些是这条具体贪心路径的结果，
不能推广成“所有单位分数展开都不能产生好逼近”。

如果强制每一步发生最大约分，则回到行列式为1的 Farey/连分数结构。
以正单位分数从3向上逼近，程序在第15步回到333/106，第307步回到103993/33102，
第1337步回到下标306的收敛分数，第1628步回到下标430的收敛分数。
这是已有结构的重现，尚未带来独立于连分数的新捷径。

文献中的 Farey–Egyptian 展开也把单侧最佳逼近组织成正单位分数之和，见
[Ben-Amram、Kristiansen、Simonsen，§7.2，定义7.9](https://www.cambridge.org/core/journals/bulletin-of-symbolic-logic/article/on-representations-of-irrational-numbers-and-the-computational-complexity-of-converting-between-such-representations/03C51E2D8F12D418A48E4B58B51FF91C)。
[Eppstein 的算法说明](https://ics.uci.edu/~eppstein/numth/egypt/cfrac.html)亦展示
用中间收敛分数将相邻差组织成正单位分数。

## 如何复现

所有代码只依赖 Python 标准库，不调用原始千万项扫描，也不要求保存的连分数流。
复制本目录后运行：

```bash
python3 search_unit_step.py --start 22/7 --output my_certificate.json
python3 search_unit_step.py --start 355/113
python3 finite_update_check.py
python3 experiment.py
```

- [search_unit_step.py](search_unit_step.py)：给定起点，完整枚举单步候选，
  输出全局单步最佳结果、是否改善以及可选的精确有理区间证书。
- [finite_update_check.py](finite_update_check.py)：独立枚举147个不同起点，
  对24,352个其他单位分母逐个精确比较，并用增长下界排除无限尾部；
  结果见 [finite_update_results.json](finite_update_results.json)。
- [experiment.py](experiment.py)：贪心展开、最大约分路径与连分数对照。
  直接从严格 π 区间认证前800个连分数系数，结果见 [results.json](results.json)。
- [certificate_22_7.json](certificate_22_7.json)：22/7样例的精确端点证书。

严格 π 界来自
\(\pi=16\arctan(1/5)-4\arctan(1/239)\)
与交错反正切级数的有理余项界。所有判断使用整数及 `Fraction`；
标记 `approx` 的小数字段仅用于显示，显示相同的两个端点不表示区间宽度为0。
命令行证书中的精确分子分母使用带 `0x` 前缀的十六进制整数，以支持更高精度。

## 研究边界

完整枚举需要分解起点分母 \(q\)，所以候选少不等于能高效处理几十万位分母。
当前命令行研究版使用试除法，限制起点分母最多40 bit；分解 \(q\) 后将指数加倍，
而不是直接试除 \(q^2\)。如果精确区间尚不足以决定候选或排名，程序停止并要求
增大 `--terms`。它不会用浮点猜测替代证明。

单步最优也不保证每一步都改善，更不等于多步整体最优。
本轮把“约分是否会足够大”的问题转成了明确的整除条件和候选集合。
进一步研究多项联动时，需要保留这种实际分母评分，不能仅优化余项的下降速度。
