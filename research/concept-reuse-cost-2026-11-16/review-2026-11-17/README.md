## 结论及准确范围

模型包含逻辑独立的布尔原子、非空合取目标、平坦二元合取定义和二元表达树。原子、名字引用和 AND 节点各收费1；每个定义正文收费3、绑定头免费；原子全部保留。

一个直观结果是：直接写“A且B”成本3；先定义名字，再引用一次，成本为3+1=4；使用两次时，直接写成本6，定义加两次引用成本5。因此在这个计价模型中，**概念命名的一次投入与复用次数需要一起核算**。

| 原断言 | 本次审阅判断 |
|---|---|
| 已付定义费的精确成本 | 正确。目标原子集为 $T$，字典为 $D$；令 $\nu(D[T])$ 为目标内可选的最多互不相交 pair 数，则 $C_D(T)=2(|T|-\nu(D[T]))-1$。下界允许重叠覆盖，没有预先假定最优表达互斥。 |
| 同一目标重复使用的阈值 | 正确。每个定义收费 $\delta>0$、同一目标使用 $q$ 次时，净收益由 $2q-\delta$ 决定。正文的 $\delta=3$ 下，单用不值得定义 pair，使用至少两次可获收益。 |
| 次模性结构分类 | 正确。候选图先限制在同一目标内；毛／净收益次模恰当且仅当各非平凡连通分量为星或三角形。三边路径给出最小反例。 |
| 正增益逐边贪心界 | 正确。在同目标且 $2q>\delta$ 时得到至少一半最优**净收益**；不是总描述成本的一半。P4 的坏次序给出紧例。 |
| 异质目标 | 正确。不同目标可要求相交定义；12／11／11／10的例子排除了把全局最优字典统一限制为匹配。 |
| 信息守恒 | 正确。保留原观察、添加其确定性函数不改变完整观察下的可区分性。删除原子后的反例也成立；这不等于描述、计算或比赛路线一定改善。 |

同一目标的结论不能直接推广到异质语料；目标外无关候选边也不能用来宣告某目标的收益非次模。
