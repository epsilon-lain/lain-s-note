# 单线的整数时钟、斜率与整段运动

把整数节点的集合固定下来以后，仍有两个自由度可研究。一是相邻节点按什么顺序出现，二是走过相邻节点用了多久。本笔记给出两种明确的走法。第一种用实际整数时刻之间的斜率变化读出既约分母，第二种用同一条高维线的连续行程表示整条目标轨迹。第一种会重访节点，与[此前每点只走一次的哈密顿射线](SINGLE_LINE_HAMILTONIAN_RAY.zh.md)具有不同约束。

## 1. 一条平面格线，用一个整数时钟反复细看同一方向

用格点 $(q,p)$ 表示方向 $p/q$，本节限于 $[0,1]$。第 0 轮从 $(1,0)$ 走到 $(1,1)$。每细化一轮，在每两个相邻旧节点 $u,v$ 之间插入 $u+v$。第 $m$ 轮有 $2^m$ 条边，在物理时间 $[2^m,2^{m+1}]$ 内每一拍走一条，偶数轮正向走，奇数轮反向走。相邻轮首尾接上。各拍内匀速直线运动，得到一条单参数连续曲线。

初始行列式的绝对值是 1，由 $\det(u,u+v)=\det(u+v,v)=\det(u,v)$，每一拍两端的行列式绝对值都是 1。这也保证边内没有别的格点，因为差向量若有公因子也会整除行列式。因此观测时刻恰是整数时刻。每个既约有理方向都会出现。具体地，一个新目标若位于相邻端点之间，其原始整数向量可唯一写成 $A u+B v$，其中 $A,B$ 是互素正整数。每次按插入点选择半边，就从较大系数中减去较小者。正整数系数和严格下降，直到两者都等于 1。这个过程同时给出找到该节点的路径。这里的格点限于锥中的原始格点，实际走过的欧氏步长可以变化。[Stern–Brocot 构造](https://fredrikj.net/fdoc/html/algorithms/number-theory/continued-fractions.html)

## 2. 直接从相邻两拍恢复平方分母

固定首次出现的一条内部方向 $r=p/q$。任选它当时的一侧邻居 $a/b$，于是 $|pb-qa|=1$。再细化 $j$ 轮，贴着 $r$ 的这一侧邻居恰为 $(b+jq,a+jp)$，两个方向仍然在相邻的整数拍被访问。记这一拍观测到的斜率变化绝对值为 $\Delta_j(r)$，则
$$
 \Delta_j(r)=\left|\frac{a+jp}{b+jq}-\frac pq\right|
 =\frac1{q(b+jq)},\qquad
 \boxed{\lim_{j\to\infty}j\,\Delta_j(r)=\frac1{q^2}}.
$$
还有一个只需两轮、无需取极限的精确版本：
$$
 \boxed{\Delta_{j+1}(r)^{-1}-\Delta_j(r)^{-1}=q^2}.
$$
这些量需要保持同一侧邻居，对走动方向取绝对值即可。几何上，两向量张成的平行四边形始终有单位面积；邻居每轮加上同一个向量 $(q,p)$。若测量夹角 $\theta_j$ 而非斜率差，则 $\tan\theta_j=1/((q,p)\cdot(b+jq,a+jp))$（点积正时），即 $j\,\theta_j\to1/(p^2+q^2)$。两种读数分别恢复同一节点的横坐标平方和欧氏长度平方。

## 3. 整条曲线的统一时间坐标

把每一轮从左端到右端归一到相位区间 $[0,1]$，反向轮再反转相位。深度 $m$ 的节点位于 $k/2^m$。把所有这样的相位映到相应斜率，并连续延拓，记所得函数为 $F$。这是经典 Minkowski 问号函数的逆（两端取 $0,1$）。连续延拓可以直接验证：斜率区间端点若有分母 $b,d$，区间长度是 $1/(bd)$。每细化一轮，$bd$ 至少增 1，故深度 $m$ 的最大长度不超过 $1/(m+1)$。嵌套区间因而确定唯一读数，且 $F$ 严格递增并满射到 $[0,1]$。实际各轮的斜率在两端点之间，归一化后也一致收敛到 $F$。[Stern–Brocot 区间和问号函数的研究背景](https://www.sciencedirect.com/science/article/pii/S0022314X08000255)

设 $s=k/2^m$ 为 $r=p/q$ 的首次出现相位（内点 $k$ 为奇数），在选定的一侧有
$$
 q^2|F(s\pm2^{-(m+j)})-r|=\frac1{j+b/q}.
$$
这里 $b$ 为该侧的初始邻居分母，对内部节点 $0<b/q<1$。端点也可用同式，取 $m=0$ 和 $b=q=1$，只取可用的一侧。由单调性夹逼，
$$
 \lim_{h\to0}\log_2(1/|h|)\,|F(s+h)-F(s)|=1/q^2.
$$
因此连分数所关心的分母平方已经编码进极限曲线在有理方向处的局部形状。

还能得到对所有分数、所有无理目标同时成立的误差界。给无理 $x\in(0,1)$，令 $t=F^{-1}(x)$，写 $\log_2^+(y)=\max(0,\log_2 y)$。对每个既约 $r\in[0,1]$ 和其首次出现相位 $s$，
$$
 \left|\frac1{q^2|x-r|}
   -\log_2^+\!\left(\frac1{2^m|t-s|}\right)\right|\le2.
$$
当 $u=2^m|t-s|\le1$ 时，选择整数 $j\ge0$ 使 $2^{-j-1}\le u\le2^{-j}$。上一式的第一个量被 $j+b/q$ 和 $j+1+b/q$ 夹住，第二个量介于 $j,j+1$ 之间。当 $u>1$ 时，已经越过初始邻居，第一个量至多 $b/q\le1$。

令 $\beta(x)=\inf_{q\ge1,\,p\in\mathbb Z}q^2|x-p/q|$。约分以及限制在 $[0,1]$ 均不改变下确界。令 $\rho(t)=\inf_{m\ge0}\operatorname{dist}(2^m t,\mathbb Z)$。在所有 dyadic 格点中，同一点以首次层数出现时，$2^m|t-s|$ 最小。因此可对上式取上确界：$\beta(x)>0$ 当且仅当 $\rho(t)>0$，且当它们为正时
$$
 \left|\beta(x)^{-1}-\log_2(1/\rho(t))\right|\le2 .
$$
这给出一个定量的二进制走法判据。$\rho(t)>0$ 等价于二进制展开中连续相同数字的长度有界，因为 $2^m t$ 的小数部分正是移去前 $m$ 位后的尾部。本笔记没有判定 $F^{-1}(\pi-3)$ 的全部数字游程，也不主张经典路径编码或上述推论具有文献首创性。

**一个算到具体时间位置的例子。** 对 $x=\pi-3$，令 $r=16/113$（即 $355/113-3$），其左右初始邻居为 $15/106,1/7$。按插入规则得 $s=65535/2^{22}$。$x$ 在左侧。用严格 Machin 有理上下界得到
$$
 292 < [113^2|x-r|]^{-1}-106/113 < 293 .
$$
所以 $2^{-315}<s-F^{-1}(x)<2^{-314}$。这个区间认证了一个极近的相位，也显示有限深度仍无法限制后续所有深度。可在本目录用下列 Python 片段复算：

~~~python
from fractions import Fraction
from verify_round2_pi import pi_bounds

lo, hi = pi_bounds(10**40)
values = [1 / (113**2 * (Fraction(355, 113) - z)) - Fraction(106, 113)
          for z in (lo, hi)]
assert 292 < min(values) <= max(values) < 293

a, b, c, d = 0, 1, 1, 1
left_index = depth = 0
while True:
    depth += 1
    left_index *= 2
    p, q = a + c, b + d
    if (p, q) == (16, 113):
        break
    if 113*p > 16*q:
        c, d = p, q
    else:
        a, b = p, q
        left_index += 1
assert (depth, left_index + 1, a, b, c, d) == (22, 65535, 15, 106, 1, 7)
~~~

## 4. 高维的另一种走法可以表示一整段运动

这里换用不同的线和观察规则，保留连续的整数拍，连中间的行程也要复现。令 $c_0$ 是坐标趋于零的实数序列空间，距离取坐标差的最大范数。每一拍的位移可取任何有限支撑、非零、坐标全在 $\{-1,0,1\}$ 中的向量。这些位移可数，把所有有限位移串排列后串联起来，每拍直线插值，得到一条固定的线 $\Gamma$。可数枚举可按串长和最大活动坐标的共同上界逐层进行。需要途经每个有限支撑整数节点时，在这些串之间插入有限连接步即可。

**整段逼近定理。** 对任意从 0 出发的 1-Lipschitz 目标轨迹 $f:[0,1]\to c_0$ 和任意正整数 $N$，存在整数起点 $k$，使
$$
 \sup_{0\le s\le1}\left\|\frac{\Gamma(k+Ns)-\Gamma(k)}{N}-f(s)\right\|_\infty\le 1/N.
$$
常数 1 最优。目标 $f=0$ 时，第一步结束的误差就等于 $1/N$。加上时间坐标 $(t,\Gamma(t))$ 可使高维线自身无自交，同时保留全部运动读数。

证明如下。$f([0,1])$ 紧，因此选取有限 $d\ge1$ 后，所有目标点在前 $d$ 维以外的坐标绝对值均不超过 $1/N$（用有限的 $1/(2N)$ 网及各网点的消失尾部）。在第 $j$ 拍，把前 $d$ 个坐标的 $N f_h(j/N)$ 分别舍入到与 $j$ 同奇偶的最近整数，平局时向上取。误差至多 1。相邻两个目标值相距至多 1，舍入后必相差 $+1$ 或 $-1$：等价地，$j+N f_h(j/N)$ 每步增加 $[0,2]$ 内的量，舍入到最近偶数时只可能维持或增加 2。其余坐标置零，便得到一个允许的 $N$ 步串。原线中确有完整的一段等于它。在每个活动坐标，插值轨迹的归一化斜率为 $+1$ 或 $-1$，与目标的差在这一拍内单调，所以整拍误差都满足端点的界。

整数观察的代价可以单独量化。在固定 $d$ 维，令目标每两拍任选一个 $\{\pm1\}^d$ 方向，两拍内不改。两个不同目标在首个不同双拍的末端，至少一个坐标相距 $4/N$，同一窗口不能以 $1/N$ 误差兼顾两者。故最坏情况下至少需要 $2^{d\lfloor N/2\rfloor}$ 个可选起点。这一计数说明走法、观测分辨率与等待时间是三个可以证明相互约束的量。
