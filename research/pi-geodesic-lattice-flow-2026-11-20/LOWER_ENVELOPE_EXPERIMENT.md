# π 连续格流：最短向量切换实验

日期：2026-11-20  
状态：**有限范围的高精度数值实验**。精确恒等式见 CONTINUOUS_LATTICE_FLOW_FOR_PI.md；本文不把有限搜索外推为无限结论。

## 1. 实验对象

对 alpha=pi，格流为
\[
A_\pi(t)=\begin{pmatrix}e^{-t}&0\\-\pi e^t&e^t\end{pmatrix}.
\]
整数向量 (q,p) 的长度平方是
\[
L_{q,p}(t)^2=q^2e^{-2t}+(p-\pi q)^2e^{2t}.
\]
固定 q 时，最优 p 是最近整数 p_q=nint(pi q)。令 E_q=|pi q-p_q|。
再乘以 e^(2t)，比较不同向量的大小等价于比较直线
\[
\boxed{\ell_q(x)=q^2+E_q^2x,\qquad x=e^{4t}\ge1.}
\tag{1}
\]
竖直格向量 (0,1) 对应直线 ell_0(x)=x。因此整个连续时间最短向量问题，化成一族直线在 x>=1 上的下包络。

两条候选直线 i,j 的切换位置满足
\[
x_{ij}=\frac{q_j^2-q_i^2}{E_i^2-E_j^2},\qquad
t_{ij}=\frac14\log x_{ij},
\tag{2}
\]
前提是 x_ij>0。这些是解析公式；数值实验只负责识别哪些交点实际出现在下包络上。

## 2. q<=200000 的下包络

使用 80 位十进精度，逐个 1<=q<=200000 计算最近整数 p_q，构造全部直线，再用单调凸包算法求下包络。另加入竖直向量 (0,1)。

## 3. 一个重要观察：最短向量不是“所有收敛分数”

pi=[3;7,15,1,292,1,1,1,2,…]。前几个连分数收敛分数与本实验的活跃状态对比如下：

| 收敛分数 p/q | q|pi q-p| | 在本次下包络中活跃？ |
|---|---:|---|
| 3/1 | 0.141592653589793… | 是 |
| 22/7 | 0.061959974100131… | 是 |
| 333/106 | 0.93505573491683… | 否 |
| 355/113 | 0.003406311930138… | 是 |
| 103993/33102 | 0.633219272976002… | 否 |
| 104348/33215 | 0.365863809067949… | 是 |
| 208341/66317 | 0.538117239746245… | 是 |
| 312689/99532 | 0.288712411619409… | 是 |

因此，连续格流自动筛选的对象不是“所有连分数收敛分数”，而是由两项竞争成本 q^2 与 E_q^2 决定的下凸包顶点。某个收敛分数也可能被另一个分母更大、但误差更小的向量在所有时间上压过。

特别地，103993/33102 的绝对误差比 104348/33215 大，且它的 (q^2,E_q^2) 点位于下凸包上方，因此从未成为当前欧氏格流的最短向量。它仍是很好的有理逼近；只是按本模型的欧氏长度权重，它不是活跃状态。

## 4. 切换时间与单个向量的平衡时间不同

每个向量自身的最短长度发生在
\[
t_q^*=\frac12\log\frac q{E_q}.
\]
但它进入全局最短向量下包络的时间，是与前一个活跃向量的交点 t_ij，二者一般不同。

例如：
- 355/113 自身平衡时间约为 7.56845，但它在 t≈4.72632 已成为全局最短向量；
- 104348/33215 自身平衡时间约为 10.91350，但在 t≈10.44596 就进入下包络。

这个区别很重要：全局最短向量的切换是两个移动长度相等，而非某个向量恰好到达自己的最短时刻。

## 5. 数学上能严格保留的结论

以下三条不依赖本次数值实验：

1. 对每个 q，只需检查最近整数 p_q，因为其他 p 的 |p-pi q| 更大且第一坐标相同。
2. 比较最短向量等价于比较直线 ell_q(x)=q^2+E_q^2x，其中 x=e^(4t)。
3. 活跃向量必须是点集 (q^2,E_q^2) 的下凸包顶点；若一个点被其他点的凸组合严格压在上方，它不可能活跃。

本次列出的具体活跃序列、切换小数和连分数对照，是 q<=200000 的高精度有限实验，不是无限定理。精确证明某个给定切换只需对相应的有限候选做严格区间比较；要证明整个无限活跃序列，还需要控制所有更大分母。

## 6. 复现

运行 pi_lattice_flow_experiment.py，依赖 mpmath。程序：
- 以 80 位精度计算 pi 与最近整数误差；
- 对 1<=q<=200000 构造直线；
- 用单调凸包求有限下包络；
- 输出活跃向量、切换时间、各自平衡时间；
- 计算前若干连分数收敛分数并标记是否活跃。
