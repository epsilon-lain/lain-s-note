# 从整数定义到 π 逼近：高度、局部约束与可用证书

2026-11-11。研究对象为 Elliot Glazer 项目 *Z is Diophantine in Q*, Version15。固定源码提交 `511529bbe9d635194f0c9d925709e77a5d3afa64`、主 TeX Git blob `832597b48dc3c1c28c9e960d40565016131492c2`。本轮针对内部机制阅读，没有审完约四万行的全部证明，也没有认证其主定理。

**找到可以迁移的机制：把同一对象的实精度和算术高度绑定，再利用非零整数的间隙强迫精确关系。本轮提炼了独立可证明的费用引理和辅助形式证书；还没有为 π 构造出满足无限指标条件的新形式，没有新的好逼近或坏逼近结论。**

## 1. 原稿中真正迫使有理数等于整数的一步

原巨大构造的 `sec:bridge` 区分两种对象：椭圆曲线点编码的整数索引 n，以及外部的普通有理数 t。它为**同一个平移参数 κ**安排两类条件：

\[
|t-n|<e^{-B(n,\kappa)},\qquad h(t)\le B(n,\kappa).
\]

第二个条件由接触素数的整除测试和高度定理导出。对既约 `t=a/b`、`b>0`，`h(t)=log max(|a|,b)`。如果 t≠n，则 a−nb 是非零整数，故

\[
|t-n|\ge1/b\ge e^{-h(t)}\ge e^{-B(n,\kappa)},
\]

与严格的精度条件矛盾，因而 t=n。这最后一段是可独立验证的初等推理；生成 Close、Test 和高度接口的深层算术论证仍属于原稿本身。

这给当前研究的明确要求是：压小余项时，同时证明生成它所需的整数系数、分母或见证高度没有超出同一尺度。详见 [SOURCE_READING.md](SOURCE_READING.md)，其中记录了具体标签、版本角色和未审查的依赖。

## 2. 接到 π 的一个实际辅助形式接口

这个引理对任意实数 α 都成立。若有两组整数 `A_i,B_i`，行列式 `A0B1−A1B0≠0`，并对给定正整数 q 满足

\[
q|A_i\alpha-B_i|\le\frac12\qquad(i=0,1),
\]

则任意整数 p 都有

\[
\boxed{|\alpha-p/q|\ge\frac1{2q\max(|A_0|,|A_1|)}.}
\]

理由是两个整数 `A_i p−B_i q` 至少一个非零。它的绝对值至少1，再扣除辅助余项预算即可。两个独立形式也处理了目标分数可能恰等于某个辅助分数的例外。

因此，若未来能在每个 q 的尺度上生成两组 π 形式，且一致满足 `max|A_i|≤Cq`，就得到统一平方分母下界。这三个条件必须同时成立；原稿的整数可定义性没有自动提供它们。本轮只给出可检查的接口，不把它当作 π 已满足的性质。

为了让接口可运行，`certificates.py` 用**输入的已知分数** 22/7、355/113 构造形式 `(A,B)=(7,22),(113,355)`，以严格有理 Machin 区间认证：

\[
1\le q\le56\quad\Longrightarrow\quad
|\pi-p/q|\ge\frac1{226q}\quad\text{对所有整数 }p.
\]

这是有限范围的使用示例，不是新逼近、纪录或无限下界。另用 √2 的 Pell 对，在不计算浮点平方根的情况下独立检查了线性形式和多项式版本，各覆盖3045个既约分数。完整证明和更一般的多项式／见证高度指数接口见 [TRANSFER_LEMMAS.md](TRANSFER_LEMMAS.md)。

## 3. 四次多项式很小，不代表接近合法整数见证

给定整系数二次残差 `f_i`，全部有理坐标分母的最小公倍数为 L，则

\[
L^4\sum_i f_i^2=\sum_i(L^2f_i)^2\in\mathbb Z_{\ge0}.
\]

所以非零时，残差平方和至少为 `L^−4`。这个四次指数不能仅靠“整系数、总次数四、共同分母 L”改进。

一个明确例子是

\[
G(x,b,s,t)=(x-b)^2+(sb)^2+(st-1)^2.
\]

其有理零点对 x 的投影恰为 `{0}`，但对任意固定非零有理 x，取 `b=x,s=1/M,t=M`，仍有 `G=x²/M²→0`。若取 `x=b=s=1/L,t=L`，则共同分母恰为 L，且 `G=L^−4`，达到间隙下界。

因此，将算术条件改写成多项式后，不能直接最小化未经计费的实数残差，再把很小的输出当成接近整数的证据。程序应同时记录 L 和整数归一化残差 `L⁴G`。类似包装能保留任意二次系统的精确投影，却使固定不合法输入也有任意小残差；该反例不依赖原稿主定理正确。

## 4. 抽出的局部映射也计算了完整分母费

最终222变量构造采用

\[
\beta=2504+51X^2,\qquad
r_4=\beta(\beta-1)(\beta-2401)(32\beta+343),
\qquad R=\frac{149^{2N+1}r_4}{1+149^2r_4},\quad N\ge1.
\]

这是最终版本的四因子改造；保留的248变量前身曾使用五因子。局部模平方计算保证 R 的149赋值总为正奇数。另有初等恢复步骤：一旦 β 为整数，由51平方自由便能推出 X 为整数。局部奇赋值本身还没有完成整数定义。

令 X=p/q 既约。四个接触因子清分母后成为整数二次式

`51p²+2504q²`、`51p²+2503q²`、`51p²+103q²`、`1632p²+80471q²`。

它们两两公因子整除固定系数行列式；在 `{2,3,5,7,17}` 之外，各因子的素数支撑不重叠。这个精确结论可以用来核算相关二次式的共同因子，不能据此声称需要的素数必然出现。

本轮进一步算出了 R 的**精确原始约分因子**：

\[
g=2^{\min(5,2v_2(q))}\,
3^{4[3\mid q]}17^{4[17\mid q]}149^{2[149\mid q]}.
\]

这里 `[ℓ|q]` 为整除指示量，`v_2(q)` 为 q 中2的指数。因此 g 有与 p、q、N 无关的固定上界。在 `3≤p/q≤4` 上，R 的既约分母按 `q⁸` 增长；其完整乘法高度还要计入 `149^{2N+1}`。

这项费用并不否定该映射在原整数定义中的作用。它明确说明：如果把它拿来当作我们分数的坐标变换，局部标记的取得需要支付高次分母费用。证明及适用范围均在 TRANSFER_LEMMAS 中。

## 5. 验证、文件及下一步

本轮分开做了原文定点阅读、引理推导和独立复核。独立代理审阅不是外部同行评审；有限算术检查补充符号证明，不替代原稿的深层论证。

从本目录运行，仅用 Python 3 标准库：

```sh
python3 certificates.py
python3 independent_check.py
python3 independent_example_check.py
```

`certificates.py` 直接用有理数 β 和 r4 计算映射、缩放反例以及有限 π 证书，结果在 `examples.json`。`independent_check.py` 使用齐次整数形式、直接 gcd、模149的全部剩余类，以及精确有理平方比较；结果在 `independent_results.json`。`independent_example_check.py` 再用齐次公式、展开的四次多项式及更窄的 π 区间复核具体示例，记录于 `independent_examples.json`。审阅范围和版本区别见 [INDEPENDENT_REVIEW.md](INDEPENDENT_REVIEW.md)。

本轮找到的迁移方向是：把整数间隙、实际分母和实余项变成同一个候选上的三份可核验预算。**还没有得到对 π 足够强的统一预算。** 后续构造仍须从 π 的积分或递推产生满足这些接口的对象，而不是仅给整数约束再增加辅助变量。这里没有改变仓库既有的构造研究目标，也没有预设 π 坏逼近或非坏逼近。
