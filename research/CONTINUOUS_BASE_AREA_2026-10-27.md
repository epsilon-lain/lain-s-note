# 连续进制中的两种面积延拓

2026-10-27。接续 NEEDLE_AREA_RESIDUAL_2026-10-27.md。以下截断射线面积模型沿用固定原点、横坐标 0≤t≤r 的约定。本文是初等推导，不声称新颖性；没有 Lean 核验，不解决 π 的有理逼近问题。

设 x=π−3∈(0,1)，实数 r>1，实数进制 β=r+1。标准数位必须是整数。对固定正整数 q，先前的最小面积是 A(q)=q||qπ||/2=q||qx||/2。注意由整数样本本身不能唯一决定连续延拓。

## 延拓一：整数倍 1/r 叠加

令整数 a 任意，参考射线斜率为 a/r，定义

G(r) = min_{a∈ℤ} (r²/2)|π−a/r| = (r/2)||rπ||。

这是以整数个 1/r 相加拟合整个 π 的实数参数延拓。对于非整数 r，a 可能大于 β−1，a/r 不必是一个合法单一数位的恒定波；它依然是整数个 1/r 叠加产生的方向。

由 ||rπ||=π dist(r, π⁻¹ℤ)，有 G(r)=πr dist(r,π⁻¹ℤ)/2。它在 r>1 上连续、非负；零点是 r=a/π（a∈ℤ, a/π>1）。π 无理，所以这些零点均非整数。固定 a，局部接近零点时 G(r)=(πr/2)|r−a/π|；它是折角而不全局可导。并非所有 r 都只有零点才能给出非常小的面积：取 c_a=a/π 与

δ_a = min(e^(−a²), dist(c_a,ℤ)/2, 1/(4π)),   r_a=c_a+δ_a。

对于正整数 a 足够大，δ_a>0（因为 c_a 无理），r_a 非整数，r_a 不等于任何零点，且 ||πr_a||=πδ_a；于是

0 < G(r_a) ≤ (a+π) e^(−a²)/2 → 0。

这构造出偏离零点、又非整数的实数参数，其面积依然趋零；距离零点的大小是选择参数时精心设定的，并不是从 π 的有理性质得到的信息。

## 延拓二：固定整数部分并研究合法数位横线

定义

F(r) = min_{n∈ℤ} (r²/2)|x−n/r| = (r/2)||rx||。

对于 r>1，最近的 n=⌊rx+1/2⌋ 满足 0≤n<r：因为 x≈0.14159，(1−x)r>1/2。于是 β=r+1>n+1；当 n>0 时该横线确实是 β 进制合法常数数位 0.nnn…，其值为 n/r。n=0 对应平凡零横线。将整数部分 3 加回，参考方向是 3+n/r，非整数 r 时不是整数分子 a/r 的同一方向族。

F(r)=xr dist(r,x⁻¹ℤ)/2；零点 r=n/x，对应 β=1+n/x，正是先前进制空间的无限平直曲线与固定 x 水平线的交点。同样可在这些非整数零点附近选取非零偏移，使 F 的值比任意指定的正衰减序列还小。

G 与 F 都是连续、分片二次、非负的函数，并在所有正整数 q 上相等，因为 qπ−qx=3q 是整数。但一般非整数 r 上 G(r)≠F(r)，例如在 r=1/x 处 F=0；若 G 也为零则 π/x=π/(π−3) 是整数，导致 π 为有理数，矛盾。这明确说明不同延拓对同一整数问题给出不同的实数行为。

## 整数采样的真实缺口

只对整数 q 采样，在任一延拓中均有

A(q) = xq dist(q, x⁻¹ℤ)/2。

因此目标问题等价于研究整数 q 到零点格点 n/x 的距离是否能在无穷多个 q 上小于任意给定倍数的 1/q。任意实数参数可以恰好落在零点或无限接近零点，不能说明整数 q 有同样的命中速度；连续性与零点的存在也不能排除这种命中。

更明确地，liminf A(q)=0 等价于对每个 ε>0 存在无限多个整数 q≥1 和整数 n 使 |q−n/x|<2ε/(xq)。得到一致正面积界则要求存在 c>0，使所有整数 q≥1 均有 dist(q,x⁻¹ℤ)≥c/q。两种均是 π 专属算术结论，不由连续图形独立给出。
