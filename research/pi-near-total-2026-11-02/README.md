# 近全逃逸：同列预算、精确消去与真实非零结构

2026-11-02。接续[周期子式增长与近全逃逸集中](../pi-escape-envelope-2026-11-01/README.md)。本轮完成四项可核验结果：时间阶数的同列约束、按真实选列修正核估计、不可消除的算术次数成本，以及一维近全逃逸的完整周期秩构造。

**没有证明或否证 π 的坏逼近性，没有找到新的 π 有理逼近纪录，也没有独立认证所给 OpenAI 原稿的 Theorem 2.1。** 本轮定理在各自明确的模型和参数区间内成立；它们没有补齐原调查关键高维路径的最后估计。

## 1. 新增的精确消去机制

在同一批移位列 \((Y-1)^hX^\alpha\) 上，设

\[
\Gamma_i=\sum_{\text{目标行}}a_i-\sum_{\text{源行}}\beta_i,
\qquad
\Delta_{\rm time}=\sum_{\text{源行}}s-\sum_{\text{列}}h.
\]

输运系数和周期子式同时非零，必须满足

\[
0\le\Gamma_i\le D_i,
\qquad \boxed{|\Gamma|\le\Delta_{\rm time}}.
\]

原因是输运增加一个空间导数阶，就必须减少一个时间导数阶；而列 \((Y-1)^h\) 至少需要时间阶数 \(h\) 才能被观测到。如果所选列恰好用满源行的总时间阶数，即 \(\Delta_{\rm time}=0\)，任何非原位输运都会让目标时间预算不足，其周期子式严格为零。

一个完整 Hermite 阶梯确实实现这种饱和。其边界相对算子严格块下三角，故

\[
\det(B+\eta RB_O)=\det B
\]

对所有 \(\eta\) 成立。按时间支撑选取对角 Gram 权重，还能使上界的下确界精确等于 1。这不是浮点相消。

但关键高维族满足 \(w_0>(m+2)v_0\)，于是

\[
\frac{\Delta_{\rm time}}{MH}
\ge\frac1{(m+2)v_0}-\frac1{w_0}+o(1)>0.
\]

因此这条“用满时间预算”的消去证书不能直接迁移过去。它排除的是一种具体机制，不是其他方法。

详见 [TIME_GRADE_CANCELLATION.md](TIME_GRADE_CANCELLATION.md) 与[独立审查](INDEPENDENT_TIME_GRADE_REVIEW.md)。

## 2. 修复真实列核中的主要指数损失

原来的热核比较把每一列都按最大预算 \(H\) 收费，得到 \(q^{-MH}\)。外幂 Cauchy–Binet 允许保留**同一批不同列的真实总次数**：

\[
|\det B_{J,C}|^2
\le q^{-E(C)}\det G_\infty(q)[J],
\qquad E(C)=\sum_{c\in C}\deg_w(c).
\]

对所有允许列求和时，以最大可能总次数 \(E_{\max}\) 代替 \(MH\) 仍成立。在一个完整、真实的多变量 jet 模型中，旧估计即使优化 \(q\) 也多出正的 \(MH\) 主指数；新估计把这项损失降为 \(o(MH)\)。

这个模型没有边界逃逸。对于当前关键族的半密度选列，统一能量节省只有相对 \(O(1/m)\)，尚不足以宣称端点闭合。

详见 [EXTERIOR_COLUMN_ENERGY.md](EXTERIOR_COLUMN_ENERGY.md) 与[独立审查](INDEPENDENT_EXTERIOR_ENERGY_REVIEW.md)。

## 3. 挑低成本列不能消除全部算术障碍

在固定正比例选取不同原始列时，随维数增加，所选列的平均空间加权次数趋向 \(H\)。因此关键半密度族中，同一非零原始子式的次数差满足

\[
\frac{w\cdot D}{MH}\longrightarrow1-\theta=\frac12
\]

（先对每个固定参数取 \(H\to\infty\)，再取 \(m\to\infty\)）。若每坐标真实算术权重与 \(w_i\) 的比值一致趋向 1，相应清分母成本也趋向 \(1/2\)。这描述的是已证明算术下界中的分母指数，不是实际行列式大小的下界。

新的同列解析界保留

\[
D=\Gamma+E,
\]

其中 \(\Gamma\) 是源到目标的次数增量，\(E\) 是目标到选列的剩余次数。误差抑制和解析增长必须沿这两部分一起计费，不能只看移出行数。

详见 [COLUMN_COST_AND_RESIDUAL_DEGREE.md](COLUMN_COST_AND_RESIDUAL_DEGREE.md) 的式 (14) 与[独立审查](INDEPENDENT_COLUMN_COST_REVIEW.md)。

## 4. 近乎全部移出的目标也可能保持真实周期满秩

在明确的一维区间 \(w_0<v_0\)、\(\theta<1/(2K)\) 中，构造保留全部低阶行的目标集合，并把它们完整包含进一个辅助 Hermite 行包。这证明每个充分大的 \(H\) 都有实际周期满行秩。

先取 \(H\to\infty\)，再增大 \(v_1/v_0\)，移出比例趋向 1。输运系数是精确的非零单项式。有限的 80 行实例中，70 行移出，并找到了有理源和真实周期目标共同非零的原始列子式。

这解决了该参数区间内的整体秩问题。它没有给出关键高维区间的构造、一般共同原始列定理、非零子式的定量大小下界，或完整外幂总和不相消的证明。

详见 [NEAR_TOTAL_PERIOD_RANK.md](NEAR_TOTAL_PERIOD_RANK.md) 与[独立审查](INDEPENDENT_NEAR_TOTAL_RANK_REVIEW.md)。
