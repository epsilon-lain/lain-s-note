# 外幂重组、平方误差律与真实周期上的多维反例

2026-11-01，接续[精确边界迁移](../pi-boundary-transport-2026-11-01/README.md)。目标是寻找能直接形成端点矛盾的整体抵消机制。**本次没有证明 π 是坏逼近数，也没有构造 P2848 的反例。** 得到的是精确重组定理、一维平方律，以及对其直接多维推广的严格反例。

## 1. 从逐行展开推进到完整行列式系数

迁移保留中心 j 和总导数阶 N=s+|β|。按这两个指标分组后，每个目标行集的聚合系数恰好为

\[
\prod_{j,N}\det\left[\binom a\beta\right]
(-\zeta)^{\sum a-\sum\beta}.
\]

同一目标集的所有逐行抵消已进入整数 Pascal 子式。每组的目标行数必须与源行数相同，否则整个系数为零。二维确有“每种分配非零、合起来却为零”的例子。

[分组证明、零系数例子、取整网格构造](exterior/EXTERIOR_TRANSPORT.md)

## 2. 找到了尖锐的一维平方律

在一个横向坐标、一个固定导数阶组内，若 k 个目标越出原包，则聚合项至少含 k² 次误差因子。原因是目标导数行必须互不重复。该次数可以达到，并非松估计。全部 b 行移到紧邻外部指标时，系数精确等于 (-ζ)^(b²)，整数因子为一。

一维边界块还能写成“对角矩阵 × Cauchy 矩阵 × 对角矩阵”，所有子式有乘积公式。[交错和、薄层界及 Cauchy 分解](alternating/ALTERNATING_BOUNDARY_SUPPORT.md)。权重分离本身不保证额外的统一指数抵消；文中给出精确下界及可行的反例族。

## 3. 多维平方律的漏洞在真实周期上仍然存在

不同横向分量形成不同格点纤维，在已构造的保留纤维选择中，最小误差次数可以降为各纤维替换数的平方和，不能普遍写成总替换数的平方。

[完整有限证书](fibers/FIBER_ESCAPE_AND_ACTUAL_PERIOD.md)使用 m=2、K=2、H=20 的完整 156 行源包，从 242 个允许单项式中选出同一组 156 列，证明：

- 原矩阵在真实有理中心 2i(22/7)、2i(355/113) 处非零。
- 两个边界替换的聚合迁移系数是 4ζ₁²，相应真实周期子式非零。
- 进一步合并**所有目标集**后，形式边界标记 η² 与误差 ζ₁² 的系数仍非零；不仅是某一个项幸存。

最后一点用两条独立计算路径认证：以 s! 逐行缩放后，在形式周期 Z=1、模 65537 下，该系数为 57067。它是非零整系数多项式，借用已知 π 超越性即可保证在真实周期 Z=2πi 处不为零。没有把 Z=1 当作指数函数周期，也没有把有限域看作整个有理数域的像。

这严格排除了“多维中两个边界替换必然自动得到四次误差”的通用捷径。它没有给出系数大小的下界，也不排除代入特定误差向量后或整个行列式中的进一步抵消。
