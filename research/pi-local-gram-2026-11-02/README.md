# 周期邻域的整体控制，以及一种高维延拓的限制

2026-11-02。接续[最小分母、周期小值与有理中心的真实成本](../pi-primitive-period-2026-11-02/README.md)。本轮把同一构造的直接误差下界从 \(\exp[-O(q^2\ln q)]\) 改进到 \(\exp[-O(q\ln q)]\)，并完成一个完整高维行包的精确分解。这里的改进只比较我们这条方法的前后估计，**不是 π 无理性测度的新纪录，也没有证明或否定 π 的坏逼近性**。

## 1. 控制一整片邻域，避开粗糙导数界

保留一维双频率原始列行列式

\[
P_n(Z)=\det\bigl([z^s]e^{hz}(jZ+z)^a\bigr),\qquad
j,h\in\{0,1\},\quad 0\le s,a<n.
\]

设 \(A_n=\prod_{a=0}^{n-1}a!\)，实际周期为 \(\omega=2\pi i\)，且

\[
U_n=(2\pi)^{n^2}A_n^2/A_{2n}.
\]

此前只在中心估计 \(|P_n(\omega)|\le U_n\)，再用很大的全局导数上界比较有理中心。本轮保留了形式周期与真实指数端点之间的**完整修正项**，把矩矩阵按 \([0,1]\) 上的正定多项式 Gram 矩阵归一化。归一化后的实际矩矩阵范数直接由指数权重控制，不需要把它求逆，也不需要忽略高阶扰动。

得到明确的复圆盘结论：

\[
\boxed{|P_n(Z)|<2U_n\quad
\text{当 }|Z-2\pi i|\le r_n,
\qquad
r_n=\frac1{16\cdot3^8n^4 2^{8n}(2n-2)!}.}
\]

偶数 \(n\ge4\) 时，上一轮证明的最小分母是 \(d_n=A_n^2/A_{n/2}^4\)。对既约 \(p/q\)，将 \(2p/q=a/b\) 约分；若 \(b\ge2\)，则 \(d_nP_n(ia/b)\) 非零，绝对值至少为 \(b^{-n^2/2}\)。因此，只要

\[
2d_nU_n<b^{-n^2/2},
\]

这个有理中心就不能落进上述圆盘，严格得到

\[
\boxed{\left|\pi-\frac pq\right|>
\frac1{32\cdot3^8n^4 2^{8n}(2n-2)!}.}
\]

取任意固定 \(c>e^{3/2}\pi^2/2\)，让 \(n\) 为不小于 \(cb\) 的最小偶数，则充分大的 \(b\) 都满足条件；右侧的对数是 \(-2cb\ln b+O_c(b)\)。这就是本轮 \(\exp[-O(q\ln q)]\) 的来源。它仍比任何固定逆幂下界弱，不能推出统一的 \(c_0/q^2\)。

见[完整圆盘证明](next-local-period-sensitivity/LOCAL_PERIOD_DISC.md)与[独立复核](next-local-period-sensitivity/INDEPENDENT_GRAM_REVIEW.md)。有限证书使用 \(2\pi<44/7\) 和精确有理算术；没有用浮点小值代替证明。

## 2. 因子分解能节省次数，但本身仍不足够

对偶数 \(n=2r\)，两个反射行列式可以分别除去已知的零点因子，再归一化成首一整系数偶多项式 \(F_+,F_-\)：

\[
d_nP_n(Z)=(-1)^r Z^nF_+(Z)F_-(Z),
\qquad \deg F_\pm=r(r-1).
\]

至少一个因子保留小的周期值；两个因子在既约虚有理中心的求值分母都精确为 \(b^{r(r-1)}\)。这使直接导数比较的主损失系数减半，但仍是 \(\exp[-O(q^2\ln q)]\)，弱于上面的圆盘法。没有证明进一步的一般低次分解，也没有把有限例子的不可约性外推。

见[整数反射因子](next-low-degree-factorization/PRIMITIVE_REFLECTION_FACTORS.md)与[独立复核](next-low-degree-factorization/INDEPENDENT_REFLECTION_FACTOR_REVIEW.md)。

## 3. 完整高维行包：深度与维数的作用不同

我们构造了带 \(d\ge1\) 个法向坐标、深度 \(N\ge2\) 的完整源行包和合法原始单项式列。其实际原始矩阵按法向次数排列后，上三角分块，因而精确满足

\[
\mathcal P_{N,d}(Z)
=\prod_{k=1}^{N}P_{2k}(Z)^{\binom{N-k+d-1}{d-1}}.
\]

这把最小系数分母的节省确实带到了一个多维构造，但也揭示了限制：

- **固定深度、增加维数：零点集合完全不变。** 只会改变已有零点的重数，不能产生更接近周期的新零点。
- **固定维数、增加深度：最小清分母后的周期值趋于零。**
- **固定深度、增加维数：该周期值最终趋于无穷。** 最外层大量重复 \(P_2(Z)=-Z^2\)，在 \(2\pi i\) 的绝对值为 \(4\pi^2>1\)，它们最终占主导。

这两个极限不能互换。上述结论仅属于这个明确的分块延拓；没有排除其他有真正坐标耦合的高维方法。此族的选列密度趋零，也未进入原稿的关键半密度、分离对数权重范围。

见[完整多维分解及两个极限](next-highdim-content-transfer/COMPLETE_NORMAL_BLOCK_PRODUCT.md)与[独立复核](next-highdim-content-transfer/INDEPENDENT_NORMAL_BLOCK_REVIEW.md)。
