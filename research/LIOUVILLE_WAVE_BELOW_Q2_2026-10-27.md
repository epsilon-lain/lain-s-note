# 刘维尔数的进制波与 1/q² 比较线

2026-10-27。研究此前长方形积分中的非负波面积 E_p，与 1/q² 的关系。这里给出基于标准刘维尔常数的直接证明，不声称该数及其经典逼近性质的新颖性。结果未经过 Lean 核验，也不对 π 作无穷结论。

## 1. 目标与记号

令 L=Σ_{j≥1}10^(−j!)∈(0,1/5)，q_k=10^(k!)，p_k=q_k+1。第 k 次截断为 n_k/q_k，其中 n_k 是整数；记尾部 δ_k=L−n_k/q_k。

首项为 10^(−(k+1)!)=q_k^(−(k+1))。对于 k≥2，后续项间隔足够大，故

    q_k^(−(k+1)) < δ_k < (11/10)q_k^(−(k+1)).       (1)

这里 k=2 时 L≈0.110001000…，q₂=100，n₂=11。

在整数进制 p_k 下以贪心规则展开 L。记第 j 位为 d_j。n_k 是合法数位：0<n_k<q_k，因为 0<L<1/5。

## 2. 精确的数位波图案

对所有 k≥2，前 k 位均为 n_k，紧随其后的一位为 n_k+1：

    d₁=⋯=d_k=n_k,    d_{k+1}=n_k+1.                 (2)

证明：暂时假设前 j 位均为 n_k，将小数重构公式解出第 j 位后的余数，可得候选值

    R_j = L + (p_k^j−1)δ_k。

从 j=1 起，只要各 R_j∈[0,1)，逐位取整的数字确实都是 n_k。q_k≥100 且 q_k≥10(k+1)；利用 (1) 和 (1+1/q)^m≤1/(1−m/q)，j≤k 时

    R_j < 1/5 + 2·(11/10)/q_k < 1。

这里使用 p_k^k<2q_k^k。于是前 k 位确为 n_k。

在下一位，p_k^(k+1)−1>q_k^(k+1)，由 (1) 下界有 R_{k+1}>1；上界由 p_k^(k+1)/q_k^(k+1)≤10/9 给出

    R_{k+1} < 1/5 + (10/9)(11/10) < 2。

因此下一次取整恰为 n_k+1。注意 R_{k+1} 在这里是按“假设下一位仍为 n_k”计算的候选量，并非真正取整后的余数；它落在 (1,2) 正说明实际数位增加1。

## 3. 非负波面积严格处于比较线下

沿用上一篇的定义，E_p=Σ_{j≥2}|d_j−d₁|p^(−j)。由 (2)，第 k+1 位贡献恰好是 p_k^(−(k+1))。以后的每位差至多 q_k，而等比尾和为

    q_k Σ_{j≥k+2} p_k^(−j) = p_k^(−(k+1))。

故不需要调用带符号距离，就能得到

    p_k^(−(k+1)) ≤ E_{p_k} ≤ 2p_k^(−(k+1)).        (3)

特别地，每个 k≥2 都满足 E_{p_k}<1/q_k²，并且

    q_k² E_{p_k} ≤ 2q_k²/(q_k+1)^(k+1) → 0。        (4)

这精确实现了：在一串可明确给出的整数进制上，刘维尔数的非负波面积比 1/q² 小，而且相对它越来越小。比较的是取样点 q_k，不是证明全部 q 的曲线始终在 1/q² 下。

例如 k=2：p=101，前三位确为 [11][11][12]；对应的 E_101 在 1/101³ 与 2/101³ 之间，且小于1/100²。

## 4. 为什么不能把这些点自动连成始终在下方的曲线

例如令 Q=1000。对任意分母 1≤q≤Q 的有理数 a/q，若它与 11/100 不同，则

    |a/q−11/100| ≥ 1/(100q) ≥ 10^(−5)。

而 10^(−6)<L−11/100<2·10^(−6)，所以不同的 a/q 到 L 的距离大于 8·10^(−6)；如果它等于 11/100，距离也大于 10^(−6)。因此对所有 1≤q≤1000，

    min_a |L−a/q| > 1/1000²,
    E_{q+1} ≥ min_a |L−a/q| > 1/1000²。

这是以相同横坐标 Q=1000 的比较阈值测试所有 q≤Q；它不声称每个单独 q 都满足 E_{q+1}>1/q²。它展示出有限尺度之间的空隙，不能把先前的好点不经证明连接成整个下方曲线。

更进一步，设 Q_k=⌊q_{k+1}/(8q_k)⌋，k≥3。若 a/q 与 n_k/q_k 不同且 q≤Q_k，整数交叉相减给出 |a/q−n_k/q_k|≥1/(q q_k)≥8/q_{k+1}；减去 δ_k<2/q_{k+1} 后距离大于 6/q_{k+1}>δ_k。若它们相同，距离恰为 δ_k。因此所有 q≤Q_k 均满足 E_{q+1}≥min_a|L−a/q|≥δ_k。

Q_k≥q_{k+1}/(16q_k) 且 δ_k>1/q_{k+1}，所以

    Q_k² E_{Q_k+1} ≥ Q_k² δ_k > q_k^(k−1)/256 → ∞。

因此对这个定义的波面积，单独比较 E_{q+1} 和 1/q² 时也存在无穷多个反方向例子。好逼近依靠的是第3节的一串点，而不是所有进制都好。
